## 推荐入口

在主代码仓库执行：

```bash
./scripts/project-python -m avatar.web
./scripts/project-python -m pytest tests/ -q
./scripts/frontend.sh run test -- --run
./scripts/frontend.sh run build
./scripts/frontend.sh run e2e
```
