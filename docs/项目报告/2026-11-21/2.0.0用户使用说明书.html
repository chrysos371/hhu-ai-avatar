01 / GET STARTED

先让小海跑起来

小海是一个在本机运行、带记忆和角色状态的对话控制台。你可以打字聊天、让回复读出来、查看和纠正记忆、导入文本知识、管理提醒。 它目前面向一个人的本机使用，不是安装完就能发短信、打电话或永不离线的云助手。

只想开始聊天

先启动服务，打开终端给出的完整链接，进入“对话观测”，输入消息并发送。不使用麦克风也能用。

想使用完整模型

需要你自己的OpenAI兼容模型服务配置。没有配置时仍可启动，但只能使用规则降级，不能把它当完整智能聊天。

  1. 拿到2.0.0安装包

    本服务器发行物在 /data/Users/zrh/data/hhu-ai-avatar/releases/2.0.0。 其中有wheel、源码包、SHA256SUMS和README。若在另一台机器使用，先通过你有权限的方式复制该目录。 当前没有PyPI发布，也没有GitHub Release二进制附件。

  2. 准备独立Python环境

    声明支持Python≥3.10，本版实际验证3.10.12。下面是Linux/macOS风格Shell示例；系统及设备仍以实际环境为准。 在你自己的工作目录创建环境，不需要在代码仓库内安装，也无需安装Node来使用已打包网页。

    python3 -m venv .venv
source .venv/bin/activate
# 将wheel复制到当前目录后
python -m pip install ./hhu_ai_avatar-2.0.0-py3-none-any.whl
hhu-avatar --version
hhu-avatar doctor --require-ui

  3. 核验文件后启动

    在发行物目录可运行 sha256sum -c SHA256SUMS。上一步版本应为2.0.0；doctor是离线安装检查，不会替你验证模型账号、语音网络或麦克风。

    mkdir -p ./my-avatar-data
export HHU_AVATAR_DATA_ROOT="$PWD/my-avatar-data"
OPENBLAS_NUM_THREADS=4 OMP_NUM_THREADS=4 hhu-avatar web --port 8765 --db "$PWD/my-avatar-data/avatar.db"

  4. 打开带token的完整入口

    终端会显示类似 http://127.0.0.1:8765/#一段随机token 的链接，使用浏览器完整打开。 请保持终端服务运行，退出用Ctrl+C。重启后使用新打印的入口，继续指定原数据库才能保留记录。

这台服务器已经有安装环境：你也可以使用下方现成入口，无需重新安装。先确认/data挂载，示例数据库使用新的独立目录，不改原实验数据库。
findmnt /data
mkdir -p /data/Users/zrh/data/hhu-ai-avatar/artifacts/my-avatar
OPENBLAS_NUM_THREADS=4 OMP_NUM_THREADS=4 \
  /data/Users/zrh/data/hhu-ai-avatar/envs/hhu-ai-avatar-release-final-v7/bin/hhu-avatar \
  web --port 8765 \
  --db /data/Users/zrh/data/hhu-ai-avatar/artifacts/my-avatar/avatar.db

原始安装/运行说明（其中“待批准”是早期文字；当前批准以最终交付记录为准）。

需要时，再连接对话模型

安装应用不会自动下载或启动大语言模型。若有OpenAI兼容服务，在启动小海的同一终端设置下面三个环境变量，然后重新启动服务。 使用你的服务商给出的地址和模型名；示例占位符不能直接使用。请勿把真实密钥写进报告、Git或聊天截图。

export LLM_BASE_URL='https://你的服务地址/v1'
export LLM_MODEL='你的模型名'
export LLM_API_KEY='你的密钥'
# 然后按上一节的web命令重新启动

源码开发也有.env.example可供参考；发行安装建议明确使用环境变量，避免.env所在位置不同而没有被读到。 修改环境变量不会自动改变已运行的进程。doctor中的“configured”只说明配置存在，发一条普通消息才能进一步检查真实连通与回复。

没有密钥也能打开网页

可以检查安装、页面和部分确定性本地能力；普通聊天会显示降级结果。这不代表完整模型已经加载。

关于数据去向

使用远程模型时，本轮文本及获准的相关记忆上下文可能发送到该服务。点击朗读会把对应回复文字交给在线Edge-TTS服务；敏感内容可仅使用文字并选择适合自己的模型服务。

九个页面，各自做什么

页面日常用途需要留意
总览看自动情绪/角色状态、系统概况和最近管理操作。看到状态不代表真人心理评估，也不代表所有外部服务在线。
对话观测文字聊天、语音输入、回复朗读、本轮提醒查询、本人/角色切换。转写先检查再发送，联网只对本轮选择。
人设管理调整角色名称与角色设定。先生成草案，再在确认窗口核对并执行。
情绪干预查看自动状态，明确设置人工干预及原因。手动干预与自动观测分开；参数不是医学或心理诊断。
记忆中枢查事实、原话与版本，查看来源，纠错或删除。纠错保留历史；删除范围应先看预览。
知识与学习导入TXT/Markdown，预览切片、检查差异并确认；检索资料。不是PDF/图片OCR入口，不会仅凭上传按钮自动批准所有内容。
提醒创建、取消、标记完成、删除提醒；确认网页近期提示。服务和网页在线才有本机投递条件，已看到不等于已完成。
工具查看工具能力与状态。工具可用不等于模型已经实际调用或完成外部动作。
操作审计查看管理变更记录、详情及可用的反向草案。反向草案也需确认，不应当作任意数据都能一键找回。

窄屏时先点“展开导航”。直接刷新各页面仍可使用；若提示鉴权失败，重新打开本次启动打印的完整链接。

完成第一次对话

  1. 进入“对话观测”

    等待历史加载完成。查看当前“本人/角色”状态；真实姓名、偏好和本机提醒请在本人语境使用。 若当前语境未知或受限，使用界面本人切换控件独立确认，再另发新的真实请求。

  2. 写一个具体、可核对的请求

    例如：请把下面的话改成一句礼貌提醒，只输出正文：明天九点前请交设备清单。 如果重要信息未知，直接写明“未知，保留占位符”，比让系统猜更稳妥。

  3. 点击“发送消息”

    普通输入最多4000字，生成期间可以点击“停止生成”。页面可能显示经过检查的片段，最终回复会替换中间草稿。 一些来源核验或程序交付不会逐字流出，这是正常行为。

  4. 按需要查看记录或重新说明

    导航/刷新会恢复当前有效历史。旧历史若没有原始决策记录，会明确说明，不会补造。 回答不充分时，补充事实和目标；不要把“我帮你发好了”当真实投递凭据。

停止与遗忘不是一件事。停止生成/播放用于打断当前任务；已经合法保存的事实、已创建提醒不会因此自动撤销。要改正或删除信息，请到对应管理页明确操作。

让回复读出来，或用麦克风输入

听小海说话

点击某条回复旁的“朗读回复”。默认不自动播放；准备完成后可暂停、继续、拖动进度或停止。超过2000字的整条回复请改用较短内容。在线语音服务不可用时，文字仍保留。

自动分段朗读

勾选“自动分段朗读新回复”，新回复会按已确认片段顺序播放。关闭勾选会停止当前自动朗读；不想继续时点“停止播放”。

  1. 先由运行者启用本地识别

    默认ASR关闭。需要安装音频/ASR扩展并准备已下载模型目录；CPU示例见下一节。若按钮不可用，不必给浏览器反复授权，先检查服务端识别能力。

  2. 点击“麦克风输入”并授权

    使用本机浏览器的localhost入口。录音会打断当前生成/朗读。说完点“结束并识别”，最长60秒；也可上传60秒以内的PCM WAV。其他文件改扩展名不会变成合法WAV。

  3. 检查识别草稿，再发送

    识别结果填到消息框，不会自动发送。核对姓名、数字、时间和完整后文，再点“发送消息”。不想使用可取消语音输入。

可选：安装并启用faster-whisper CPU识别

在同一个应用虚拟环境准备扩展，模型须单独下载到自己有权限的本机目录；安装依赖需要网络，模型加载也需要磁盘/内存。示例不自动下载模型。

python -m pip install faster-whisper==1.2.1 "librosa>=0.10" "soundfile>=0.12"
# 当前目录按“开始使用”示例已有my-avatar-data；替换模型路径
OPENBLAS_NUM_THREADS=4 OMP_NUM_THREADS=4 hhu-avatar web --port 8765 \
  --db "$PWD/my-avatar-data/avatar.db" \
  --asr-backend faster-whisper --asr-device cpu \
  --asr-model /absolute/path/to/faster-whisper-small

本服务器已知模型在/data/Users/zrh/data/hhu-ai-avatar/models/faster-whisper-small，但上述干净发行环境默认不含ASR扩展。 切换GPU识别前需由运行者确认驱动、依赖与实际余量；首次使用建议保留CPU和手动结束。

“停顿后自动结束录音”默认关闭。打开后约1.2秒停顿会结束，8秒未检测到语音会释放麦克风；轻声或长停顿可能截掉后文。公开语料实测曾出现退化，重要内容建议手动结束并核对草稿。

小海的嘴型随实际播放进度变化；三维不可用时可以回退最小形象。当前只有有限口型锚区，不能把它当完整中文音素或声调教学工具。

提醒：区分创建、提示、已看到和完成

  1. 创建一条明确提醒

    进入“提醒”，填写“提醒内容”，例如提醒我明天上午9点核对设备清单，点击“生成提醒草案”。 在弹窗核对标题、时间与操作，确认后才落库；信息不完整时先补充。

  2. 查看编号和状态

    列表中的编号用于精确查询、取消和管理。想只查不改，可在对话页勾选“本轮仅查询提醒”，输入查询提醒编号1或查看提醒送达条件。 编号1仅为示例，请换成实际编号；没有唯一编号时会要求澄清。

  3. 收到提示时点击“已看到”

    近期未确认的提示可在返回或刷新后恢复。该按钮只记录客户端提交了确认；它不会把事项自动标记为完成，也不能证明你认真读过。

  4. 事项变化时明确管理

    想取消、完成或删除，使用提醒列表中的对应操作并核对草案。“完成”表示记录被标记完成，不是系统已经替你执行了事情。 角色扮演里的台词不会自动成为真人提醒，切回本人也不重放旧请求。

提醒的运行条件：程序必须运行并处理到期事项，网页接收还需页面在线轮询。关机或服务退出时不会自动继续投递；没有短信、邮件、电话通知通道。不要用它替代关键事项的独立可靠闹钟。

专用查询限2000字，与本轮联网互斥；切换查询模式不会发送草稿，也不会创建/取消/认领/确认提醒。查询回复保存的是当时快照，想知道现在请重新查询。

管理记忆、角色和知识

查看和纠正记忆

在“记忆中枢”按内容查找，点“来源 #编号”看原话与证据。填写纠正内容后点“生成纠错草案”，检查范围再“确认执行”。可勾选“包含历史版本”；纠错不会假装旧版本从未存在。

明确删除

删除记忆或原话前先看预览。来源删除会使依赖的当前记录/回复/缓存失效；界面清除不代表能收回你已下载的音频或实现物理介质擦除。删除和反向草案的恢复范围不应自行猜测。

区分本人和角色

用页面控件明确切换；角色姓名和剧情不应当成你的真实资料。退出角色只改变后续语境，不自动替你执行之前的剧情动作。当前来源不明确时先独立确认本人。

设置人设和情绪干预

人设名称/设定、手动情绪干预都先生成草案并确认。角色状态会自然衰减，重启后可恢复；旧用户情绪不会当成本轮新观察。手动干预是显式设置，和自动分析分列。

导入TXT / Markdown知识

“知识与学习”→“上传文件”→选择.txt/.md→“解析并生成预览”→“检查导入差异”→核对后“确认执行”。随后输入查询内容检索。复杂PDF或图片请先转为自己确认的文本。

审阅管理操作

“操作审计”里看操作详情、来源及结果。若提供“生成反向草案”，也先预览再决定；它不是对所有删除的万能撤销键。

画像与历史恢复有容量和来源边界，小海并不保证无限记忆或每句话都持久化成事实。重要姓名、偏好、预算或委托关系请说清楚，并在管理页核对实际记录。

遇到问题，按这个顺序检查

现象先检查接着怎么做
网页打不开/端口占用终端服务是否仍在；是否使用本次完整token链接；8765是否被占。关闭旧的自己启动的实例，或用--port 8766。不要停止不属于自己的进程。
远程服务器能启动，本地浏览器打不开127.0.0.1指服务所在机器，不是你的电脑。使用有权限的SSH端口转发，再从本机打开转发端口和原token。无需把服务改成公网绑定。
401/403或页面鉴权失效服务重启后token可能已变；是否漏了URL中#后面的部分。重新打开启动日志给出的完整入口，不共享token。
回复很像示例/规则答案LLM配置是否存在，服务进程是否在配置后重启。用doctor看配置，再发普通消息检查实际调用；检查服务商地址/密钥/模型名。
朗读没有声音系统音量、浏览器媒体权限、Edge-TTS网络、是否仍在准备。看页面错误；文字可继续使用。长回复拆短；缺解码/口型扩展时检查音频依赖。
麦克风按钮灰色服务是否显式加载本地ASR、模型目录是否正确。先配置识别；浏览器授权后仍失败可上传PCM WAV。
转写漏了后半句是否勾选自动停顿结束，是否录到60秒上限。关闭自动结束，用短句手动结束并检查完整草稿，避免自动发送错误内容。
发送按钮不可用历史是否加载完、当前是否生成/识别中、内容是否为空或超限。等待结束或明确停止；普通≤4000字、专用提醒查询≤2000字。
关机后没有提醒服务退出，或页面离线未轮询。重启原DB、重新查询状态；关键事项另设可靠提醒，不假设已短信投递。
删除后另一个页面似乎还留旧内容网络/版本通知是否失联。检查连接状态并重新进入；不要把浏览器已下载副本当已收回。
形象回退或嘴型不精确浏览器WebGL支持、媒体实际播放状态。可继续文字/音频；当前嘴型非完整中文音素校准，不强行解读其准确率。
侧栏为什么是v0.1这是旧界面标识，尚未同步成包版本文字。用hhu-avatar --version与安装包元数据核验；本次发行是2.0.0。
远程使用的SSH转发示例
ssh -L 8765:127.0.0.1:8765 你的账号@服务器
# 服务器端仍使用web --port 8765
# 你的本机浏览器打开 http://127.0.0.1:8765/#服务器本次打印的token

账号和服务器地址请替换为自己获准访问的配置；同一端口已占用时换一个本地端口，并相应修改浏览器地址。

保留数据、备份与正常退出

退出用Ctrl+C。下次启动继续指定同一个--db路径，不要因为想“重启”就换数据库或删除目录。 HHU_AVATAR_DATA_ROOT控制缓存等配套数据；--db明确指定记忆与会话数据库。数据库路径不是模型目录。

备份数据库推荐使用SQLite备份API，避免只复制正在写入的主文件而遗漏WAL。在应用自己的Python环境里执行下面示例，替换真实路径，备份目标必须是新文件：

python - <<'PY'
from pathlib import Path
import sqlite3
source = Path('/absolute/path/to/avatar.db')
backup = Path('/absolute/path/to/avatar-backup-new.db')
assert source.is_file() and not backup.exists()
with sqlite3.connect(source) as src, sqlite3.connect(backup) as dst:
    src.backup(dst)
print('Backup completed')
PY

恢复前先停止服务并保留原库，再用副本单独验证。此备份只覆盖SQLite数据库，不包含外部音频文件、模型、知识源文件和浏览器下载；需要它们时分别保全。

本机单用户不等于完全离线：远程模型、朗读服务、显式联网工具都可能发送相应内容到外部。请按自己的隐私要求选择配置，启动token和模型密钥不要公开。

能帮你做

聊天、草拟/修改文字、管理有来源记忆、本地提醒记录、明确查询、可选本地语音输入、在线朗读、随播放变化的形象。

不要把台词当现实动作
