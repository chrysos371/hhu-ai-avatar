# 数字人持续改进工作流 v1

本阶段是持续发现问题、积累证据的开发巡检。它不会自主提高模型权重、自动修代码、确认人设、训练、发布或给QQ发消息。只有存在后续候选改进与独立验收，闭环才会变成可证实的能力增长。

## 已运行的流程

systemd定时触发 → 非阻塞排他锁 → 重筛最近20批已落盘证据 → 检查当日预算 → 优先挑选最久未运行的完整多轮开发场景 → 隔离CharacterLibrary真实模型调用 → 规则信号去重入库 → 写报告。

- 仅本地模型接口，默认小肥鱼当前配置的profile；不支持云端模型巡检。
- 人设使用当前源码catalog的初始值，不读取正式角色persona.db、聊天记忆或主库知识。因此巡检成绩不等于线上完整配置的成绩。
- 当前10个固定开发场景（后续加入学习/写作各一项、接梗两项），轮换执行；尚未自动生成新场景、调用独立语义评委或建立独立保留验收集。
- 实验路径在每批独立目录；当前套件禁止触发外部查询工具。没有自动扫描生产对话；历史记录只通过明确指定的合成研究证据导入。
- 记录源码哈希、Git状态、开发套件、模型profile和初始人设卡。不是权重级可复现性能基准。
- 每批最多6轮，每天最多24轮，场景不可拆半。调用前先扣预算，失败停止本批。锁阻止多个worker重叠；被中断的批次标记interrupted，保留已扣轮数，下一次恢复落盘证据。
- Nice=10降低巡检客户端进程优先级，并不改变共享llama-server的调度优先级；轮数和频率限制仍是主要负载控制。

## 定时与停止

已启用系统级 `avatar-improvement-zyyh.timer`，每日北京时间02:15、08:15、14:15、20:15触发，另有最多3分钟随机延迟。Persistent支持错过计划后补跑一次，不无限补跑。服务单次15分钟看门狗防卡死；这不是训练实验截止。

所有服务定义、证据和报告在 /data/Users/zyyh 下；/etc/systemd/system仅保存指向项目unit文件的系统注册软链接。

```bash
systemctl list-timers avatar-improvement-zyyh.timer
systemctl status avatar-improvement-zyyh.service
journalctl -u avatar-improvement-zyyh.service -n 20 --no-pager

# 停止后续定时任务；若正在运行，可再停止独立巡检服务。
systemctl disable --now avatar-improvement-zyyh.timer
systemctl stop avatar-improvement-zyyh.service

# 恢复定时任务。
systemctl enable --now avatar-improvement-zyyh.timer
```

## 文件与手动使用

- data/improvement/issues.db：问题信号、出现记录、执行批次。
- data/improvement/latest.json：最近汇总；不含对话原文和凭据。
- data/improvement/reports/YYYY-MM-DD.md：按本地日期生成的报告。问题次数是历史累计，不是当日失败率。
- data/improvement/runs/<run-id>/metadata.json、turns.jsonl：模型与版本信息、完整合成对话和trace。
- experiments/improvement/development.json：开发场景，不能冒充保留测试或自动充当训练集。

在项目根目录运行：

```bash
/data/Users/zyyh/envs/hhu-ai-avatar/bin/python -m avatar.lab.improvement report
/data/Users/zyyh/envs/hhu-ai-avatar/bin/python -m avatar.lab.improvement run --max-turns 6 --daily-turns 24
```

明确导入指定合成研究记录的命令为 `import-synthetic --input data/research/.../turns.jsonl`。它按内容哈希与场景/轮次去重；不同真实执行批次出现同类问题会保留独立证据。

## 如何理解结果

`completed`只代表批次运行完成，不代表对话正确。规则包括复读、无效JSON、四字标题格式、告别误用晚安、告别追问，以及疑似不受欢迎建议、语言漂移、线下邀请。疑似项需要进一步确认，未命中规则不等于无问题。没有独立评委，没有语义通过率，不自动关闭历史问题。

问题按角色和信号类别聚合，是排查入口，不是已确定的根因；同类别可能存在多个根因。真实情绪理解、事实归属、关系连续性等仍需要进一步评测。
