# G2C13-004 隐私失效不能授予真人权限

P1，追加审计有效复现4失败，修复后待v2复测。原v1固定三轮各8通过不覆盖此不变量，保留但不据此宣称全权限完成。

真人事实存在后进入小说角色，外部连接删除该无关事实，随后输入角色姓名或提醒。Avatar与Web各两项均发生不应有的真人资料写入/真实提醒创建，见实验/privacy-authority-before.log（4失败，0.84秒）。既有SpeakerScope按版本clear为current_user，本轮初版持久状态也沿用了这个旧语义，导致丢失来源反而授予权限。

加强规则：清除所有旧控制/真人指代来源时，先前受限状态只能变为unverified，不能变成真人权限；用户需单独明确“回到现实”，随后独立真实请求才获得操作权。原本已核验current_user的普通隐私失效仍清上下文，不无故重新授权角色。内存对象的observe、分析中失效与显式纠错/遗忘，以及持久状态失效使用同一规则。

原v1 privacy_reset把删除本身当成现实退出，门槛不足。v2保留v1原协议/数据，原重置场景加入显式现实确认，并额外增加删除后姓名/提醒仍不得获取权限的两项；这是补强权限契约，不是放宽失败门槛。旧测试中“角色隐私失效后直接写真人”的断言也按此有据改变，恢复路径仍要测。
