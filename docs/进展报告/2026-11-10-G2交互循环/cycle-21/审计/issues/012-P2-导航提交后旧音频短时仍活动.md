# C21-012 / P2 导航DOM提交后旧音频短时仍活动

组合默认浏览器14通过/1失败/12跳过原轨迹保留。固定20次实际Chromium/PCM诊断中2次点击返回时目标总览heading已在DOM、旧chat已不存在、旧audio已detached，但paused=false且src仍在。后续heading等待观察与526个离页rAF样本均已停止，不能据此否认较早两次有效观察；本项是短暂资源释放窗口，不是持续泄漏或现场发生率估计。

根因与红测：useSpeechPlayer的资源释放在被动useEffect清理，DOM变更后/该清理运行前旧音频仍可继续。新目的页layoutEffect确定性观察同样未暂停/有src，1红测失败、同页普通rerender正控通过。目标把资源所有权释放移动到同步layout清理，仍捕获原audio并清理请求/对象URL；不改变旧浏览器暂停+无src断言，不添加宽限或盲目重试。
