# G2C21-003：SDK提交后取消/遗忘仍合成并返回旧回复（P1）

状态：组件/SDK实证确认，独立工作树修复中。当前主树冻结CPU研究保持不改。

sdk-tts-commit-before.json/log：实际默认Avatar，受控模型返回合成实验姓名、受控TTS记录调用参数并写0.1秒静音WAV；在实际assistant事务提交完成后，分别正常、取消token、独立连接forget。三项均TTS组件1次/终态result，忘记项actual revision=1而仍返回含旧姓名的reply/旧revision，取消项token已取消仍继续。所有临时库和文件清理成功。

范围：证明SDK编排在该交错下继续调用TTS组件且返回旧文本；没有测试真实Edge网络/语音内容/物理播放，静音WAV不证明输出了姓名语音。Web异步TTS和回合结果还有各自来源屏障，本记录不外推其失败，也不把问题当原生模型质量证据。

根因待修：默认respond仅在assistant提交前检查，提交后的可选TTS、解码和result构建缺少本轮版本/取消复核；默认SDK调用普通synthesize也未向已有cancellable TTS接口传本轮token。

目标：提交完成后、TTS前后及最终返回前复核原回合；取消或已观察到遗忘应Cancelled，不派发后续TTS/不返回旧result。已有assistant在取消前已提交，不强行回滚或删除有效历史；遗忘按原来源机制失效。能采用原生cancellable接口时传token，旧synthesize-only组件继续兼容。检查后新竞态、已开始远程请求或未验证音频文件的追溯擦除不作保证，需单独实测。

独立修复工作树用于在当前真实CPU配对冻结不变时推进，所有实现/红测/复测独立小步提交推送；合并前需当前冻结实验收尾或新基线策略，不修改正在采样的254项主树输入。
