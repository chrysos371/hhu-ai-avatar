# G2C14-001 遗忘游标跳过未跟踪用户来源

P1，开放。修前冻结9项矩阵5通过/4失败，0.297秒。实际执行run_chat、另一个Avatar或MemoryStore写入，使用不同SQLite连接；未运行交互CLI子进程、HTTP浏览器或真实模型，不作那些范围的结论。

失败：CLI等价角色输入后删除原真人资料，随后Web姓名/提醒获得真人权限；直接用户消息后删除再改名同样错误；未跟踪的普通CLI用户消息也因删除而跳过核验。原始实验/before/mixed-writer.json保存每一步用户/助手来源、profile/reminder、版本及持久scope/fence/basis。

具体链：原Web cursor=1、scope=current_user；其他Avatar提交user=3（或直接user=3）但没有更新Web控制状态；遗忘从revision0→1，把cursor推进到4（或3），仍保留current_user、清basis。下一Web回合原缺口检查查不到游标后的未跟踪用户，于是错误授予真人资料写入或创建提醒。无遗忘时相同CLI缺口已保守为unverified，不能把它称所有混合路径已修。

目标：在隐私事务推进fence之前核验旧fence后是否有未跟踪用户来源。有则只保留unverified；不读取或重放旧原文，不因隐私失效授予权限。原本受限仍受限；没有缺口的已跟踪真人及纯助手写入不被误阻断。删除前/后两种串行次序和明确现实确认恢复均保持。
