# C34-002 构建物不能按ignored根路径冒称Git来源

P3采证流程问题，已关闭。没有模型/产品故障或测试结果改变。

## 现状与审计结论

after冻结首次尝试把默认浏览器绑定内的5个frontend/dist路径一并交给Git archive。它们实际被gitignore忽略，历史核验以pathspec不存在拒绝，尚未输出freeze/DB/模型调用。失败见[原日志](../工作目录/002-系统回归/freeze-git-ignored-first.log)。当前磁盘存在及SHA一致不等于路径在某个Git提交内存在。

## 优化目标与完成情况

将实际测试的5份bundle逐字节归档在本周期，提交[路径与SHA映射](../工作目录/002-系统回归/browser-dist-archive.json)。冻结分别验证根实际构建物、已提交归档副本、浏览器实际运行SHA三者一致，并只把已提交归档路径交给Git历史核验。最终after491项历史/当前核验通过，两模型完整原生修后均使用该冻结。没有重跑筛选、修改构建物或改写既有浏览器执行记录。

保留首次失败与后续修正。之后不得把ignored产物路径直接加入宣称全部来自Git的清单；应使用明确归档映射，或直接说明只核验本地运行产物。
