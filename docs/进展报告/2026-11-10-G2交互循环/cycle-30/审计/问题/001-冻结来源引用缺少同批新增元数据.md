# C30-001 冻结来源引用缺少同批新增元数据

P2/采证来源完整性，在任何模型/GPU运行前的历史Git核验发现。初始309冻结包含relay-control-version.json，但该JSON与freeze同一提交新增，source_ref指向之前提交，历史Git不含该输入。当前工作树SHA可过，不能据此声称全部输入历史来源绑定。

实际git archive针对source_ref全部冻结输入拒绝，stderr及argv/SHA保留，未启动模型或应用。不改原descriptor，另unused-retirement；新版本先提交所有来源，再冻结，并在controller创建输出/模型前用git archive批量核验全部历史Git字节。新freeze错SHA、缺4B前置控制和源码历史身份都需通过后才运行。此为审计工具缺陷，不是产品记忆或模型质量结论。

修复：新v2冻结先提交全部309来源，controller输出/模型前用git archive校验历史字节；实际错SHA/32B缺先行4B/worker错SHA三负控通过。4B真实36回合/24OS/74调用的历史/当前source及原wire均独立核验通过。状态：该来源完整性范围关闭；初版unused descriptor不改。
