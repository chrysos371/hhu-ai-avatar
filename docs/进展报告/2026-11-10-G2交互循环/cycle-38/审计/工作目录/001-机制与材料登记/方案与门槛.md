# 隔离候选v1：计划不是回执

结构化计划仅是模型的路由假设，引用位置只能证明来源字节存在，不能证明语义正确。新机制采用已有缓冲reviewer，保留原自由草稿后再调用一次受约束JSON计划，程序只读核用户源/版本/运行时范围/实际精确注册表；可执行四类外部动作均不存在时，由确定性模板答复不可代办/无助手执行，不从原草稿、请求或用户自述生成“已完成”状态。原生模型本身仍可能出错，普通路线保留原生成，漏判/误判都是门槛失败。

模型格式或证据拒绝则保留原草稿并标记拒绝，不悄悄报告已保障诚实；来源改变/取消向上抛Cancelled。引用中的动作不能作为真实代办依据；角色/明确小说不应用现实动作替换。普通写作/用户报告等保护需逐条验证，不能以source span验证替代语义审阅。当前提醒规则路径与真实回执保持，四类外部接口的缺失不证明用户没有自己做过，也不保证本地通知送达。

开发12场景、分离保护8场景已在候选实现与新实模前登记，具体回合数由JSON材料计算；真实4B固定3重复、按场景/重复奇偶交替双臂、每臂独立DB/HTTP、每重复新provider且不宣称物理清零。全部原生wire/草稿/计划/最终/存储与规则身份分开。开发合取失败则不跑保护组，不通过改词/后处理描述冒称生成质量提升。三组相关重复不是三份独立金标。32B暂不预排。
