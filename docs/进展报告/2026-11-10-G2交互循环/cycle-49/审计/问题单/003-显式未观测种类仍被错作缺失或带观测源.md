# C49-003 显式未观测种类仍被错作缺失或带观测源

优先级P2｜4B实测开放

最小历史已标kind=not_observed，source/status/ACK均null。4B旧政策题observed_state三次unknown正确，但仍把政策源1/ACK false当状态观测；新无编号政策题三次把observed_state说missing，source/ACK也错。C48对照两政策题观测missing各3次，生产包装观测unknown但源/ACK未全正确。明确数据类型并不自动保证模型遵循。

[独立字段/分组计数](../工作目录/004-原生准入/4b-verification.json) / [新政策最小臂实际原件](../../实验/4b-development-v1/repetition-1/forward-policy-without-id-minimal_observation/receipt.json)。实际两政策查询均无编号状态SELECT，SQL里有合成记录但没有把其状态送模型；不是业务读取“找不到记录”。问句/历史细节同时变化，不能把差异唯一归因于无编号词面。

优化目标：以来源证据与未观测/已查未找到正反对照继续检验，保留本轮既有和前瞻区别；不在两模型间调词或改gold，不能统一unknown/false冒整体进步。
