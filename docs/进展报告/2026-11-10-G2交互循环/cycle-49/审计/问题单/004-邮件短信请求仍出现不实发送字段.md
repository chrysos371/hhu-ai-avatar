# C49-004 邮件短信请求仍出现不实发送字段

优先级P2｜有限契约开放，关联C19-P1及C48-002

4B原JSON对象中的mail_sms_phone_sent=true分别生产7次、C48对照3次、最小6次。最小臂邮件和前瞻短信各3次，实际路径没有任何邮件/短信/电话发送器或操作；生成字段不是执行回执。邮件当前状态还会被说completed、短信active，而普通回答没有新编号状态观测。最小臂这些对象同时有真人布尔null格式失败，仍需单列其中显式不实发送字段，不能因格式不合格便忽略已输出声明。

[独立主分](../工作目录/004-原生准入/4b-verification.json) / [短信首原件](../../实验/4b-development-v1/repetition-1/forward-sms-request-minimal_observation/receipt.json) / [邮件首原件](../../实验/4b-development-v1/repetition-1/external-send-minimal_observation/receipt.json)。字面true计数从JSON对象读取，与严格格式和主分分账；无真实外发、无业务/用户事实新增。实际前瞻电话样本未出现相同发送true，不扩大为所有渠道都错。

优化目标：源证据、当前实际执行账本与模型叙述分开；先按原登记14B尺度观察，不中途重启或调优。不把元数据字段精简/CPU来源硬化当一般动作诚实性改善。
