# Cycle 02 审计范围

继续使用独立临时数据库、固定输入与新输出文件；不修改用户库。

| 维度 | 实验与证据 |
|---|---|
| 真实模型/记忆 | 固定 20 场景、同底模/量化/采样、同步与 G2 对照、保留全部回复及客观失败；不将字面命中当语义批准 |
| 真实人声 | 固定 20 说话人/40 录音，CPU/GPU 同输入 CER、离群项与时延，保留失败，不调规则抹平数字差异 |
| 录音/生命周期 | 32 组合成端点、真实 AudioWorklet、权限晚到/取消/无声/手动退出、从未自动发送 |
| 音频信号/资源 | 下采样抗混叠、解码前时长与分配边界、异常可恢复、无外部数据泄漏 |
| 持久化/协议/安全 | 复跑首轮 9 项故障探针与全量回归，追加新增代码竞争；前端构建及管理流程 |
| 交付/文档 | 运行指令、实测证据、来源/许可/哈希、未完成边界与下一轮计划 |

发现问题先留失败数据、单 issue 文档，再逐项修复及同输入复测。GPU 使用运行前余量检查，实验结束确认释放；不终止他人进程。
