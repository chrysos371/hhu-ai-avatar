# 回合耐久与副本生命周期协议（运行前固定）

使用独立临时库和本机可控 HTTP 提供方，500 个顺序回合，每第 5 轮同 ID 重试一次，每 50 轮删除一次测试画像并核对任务清除。无真实用户数据、不调用外网模型/TTS、不使用 GPU。失败保存原始记录并早停，不缩减预定回合数来通过。

门槛：500 轮成功；同 ID 不新增用户消息；任务缓存始终≤32；删除后运行缓存为空且 SQLite 派生助手文本完成脱敏；最终无新提交也能 TTL 清理；SQLite 完整性检查 ok。另记录 50 轮后至结束 RSS 变化（门槛≤150MiB）、线程数（≤40）、数据库大小与耗时。每 50 轮保留一组原始指标。

这只是短时顺序负载/资源生命周期实验，不替代多日稳定性、真实多人流量或模型质量评测。指标受本机负载影响，不作纯性能因果推断。
