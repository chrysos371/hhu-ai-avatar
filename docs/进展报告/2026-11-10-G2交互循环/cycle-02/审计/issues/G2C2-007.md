# G2C2-007：已配置模型的服务故障被描述为未配置

级别：P2；状态：已修复，专项通过。

真实提供方异常时 Avatar 已配置且首轮调用成功，第二轮却返回“当前未接入大模型，请在 .env 配置 LLM_API_KEY”；同时结果没有生成模式字段，实验脚本 errors=0，无法结构化分辨真实回复和服务失败后的规则回复。事实/情绪认知已有 analysis_mode，但不代表回复生成可用。

同一 [原始结果](../../实验/initial-real-model-paired.json) names 等场景可复现，首轮真实 LLM 回答林岚，第二轮因模板故障降级却要求配置 key。目标：区分未配置与调用故障，保留可用的规则回复、避免泄露上游正文；结果/追踪添加生成模式，评估自动识别服务降级。注入故障专项、恢复后重试以及真实模型重跑验证。

修复为 generation_mode=llm / rules_service_error / rules_unconfigured / rules，API 决策追踪同样暴露；调用失败的提问明确提示暂时不可用，不要求重新配置 key，也不回显上游细节。同步/流式注入故障与恢复、未配置区分及 Web/主流程专项 68 passed（7.64s）。[专项日志](../../实验/generation-mode-tests.log)。真实评测据此拒绝降级污染，重跑结果另附。
