# G2C2-011：引用结束后的明确本人自述被整句丢弃

级别：P2（记忆覆盖）；状态：已修复，正反例与旧安全回归通过。

冻结 quoted_a：“朋友说‘我喜欢游泳’，而我喜欢跑步”中，引用内他人信息必须排除，但完整闭合引用之后的明确本人偏好也被 _safe_sentences 整句丢弃。数据库画像为空，不能跨会话可靠回忆。原逻辑安全上保守，不能将此问题说成引用注入绕过。

证据：[探针](../evidence/fact-verifier-before.json)。目标仅支持完整引用之后可独立确定的本人自述尾段，证据必须是原文连续片段；不回收引用前后被打断的省略指代。外层假设/问句继续作用整句，未闭合/嵌套纯引用/他人转述保持拒绝；尾段内部否定反转须保留完整范围，不凭掩码合成事实。先固定正反例，再修改并跑旧安全回归与真实场景。

实现只截取最后闭合引用后、逗号接入且以可验证本人自述开头的原文连续尾段；整个尾段保留以识别后续否定反转。外层条件/问句仍先检查，引用前事实及跨引用省略链不回收，未闭合引用没有可用尾段。同探针 12/12，引用/连接/旧事实/主流程专项 130 passed（1.04s），含跨会话保存、原文来源不变和引用内候选拒绝。见 [最终探针](../evidence/fact-verifier-after-quote.json)、[日志](../../实验/fact-quote-tests.log)。
