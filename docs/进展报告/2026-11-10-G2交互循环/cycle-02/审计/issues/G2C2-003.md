# G2C2-003：训练数据导出测试隐含要求临时目录在工作区内

级别：P2（验证可复现性）；状态：已复现，待修复。

默认命令 `python -m pytest tests -q` 在 /tmp 使用 pytest 临时目录时，数据篡改/划分验证尚未开始就被工作区写入门禁拒绝：1 failed、647 passed、1 skipped。失败点 test_automatic_export_rejects_data_tampering_and_keeps_split_disjoint。该门禁本身正确；测试没有把隔离的临时根注册为自己的工作区，依赖外部 --basetemp 位置。

证据：[完整失败日志](../evidence/python-full-before-test-isolation.log)。不能把这项解释为本轮音频功能的故障，也不能忽略导致全量验证无法直接重现的隐含环境要求。

目标：仅在该测试中用 monkeypatch 将工作区根设为 tmp_path；保留生产根路径限制，并断言测试根以外仍被拒绝。默认临时目录下单项及全量通过，原数据哈希/训练开发不交叉断言继续执行。
