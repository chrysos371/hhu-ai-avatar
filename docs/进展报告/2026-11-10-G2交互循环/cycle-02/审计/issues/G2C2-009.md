# G2C2-009：真实 4B 回复把用户的偏好说成角色自己的偏好

级别：P1（事实归属）；状态：已复现，候选方案待实验。

真实有效 v2 同题对照中，用户“室友周宁喜欢游泳，我喜欢跑步”后追问自己喜欢的运动，数据库 profile 正确为“喜欢跑步”，但两模式均答“我喜欢跑步，不过如果你喜欢游泳……”。明确的第一人称把用户偏好转成角色自述。不是抽取未存储或传输失败。原检查也标出游泳相关短语，但条件句字面命中本身不等于断言归属错误；这里以“我喜欢跑步”作为具体语义问题。

证据：[v2 完整结果](../../实验/real-model-paired-v2.json) ownership；原始提供方提示与输出另归档。双方 19/20、无 G2 新增失败，不等于此项已解决。

目标：先评估明确标注 profile 属于当前用户、回答用户信息用第二人称的通用提示，不用固定题目回复代替模型。候选默认关闭；先冻结原 20 + 新 16 场景，统一量化/种子/上下文，G2 两组仅此提示不同。36 项全部字面检查通过、预期画像正确且无新增失败/服务降级才启用；失败则保留关闭，考虑模型规模等下一循环方案，不以开发字面分代替独立语义批准。

14B 同一 v1 门槛：两组均原 19/20、追加 15/16。原 no_fact 为字面漏项误报，另登记 G2C2-013；追加 unknown_self 是真实错误：profile={}，用户只说朋友叫柳林，14B 却先问候“你好，柳林”再回答“我知道你叫柳林”。因此扩大模型没有全面解决主体归属，不能自动替换默认。后续需显式约束未确认的用户姓名，且验证首轮称呼而非只查末轮。
