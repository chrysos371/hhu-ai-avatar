# G2C2-014：实验模型选卡忽略显式 CUDA 可见集合

级别：P2（资源约束）；状态：模拟复现，待修复。

真实模型实验服务在全部物理卡中检查余量后，直接覆盖 CUDA_VISIBLE_DEVICES，没有先尊重调用方的显式集合。只执行选择代码、注入 8 张假卡且传入 mask=6，实际选择 7，证据见 [模拟结果](../evidence/gpu-visibility-before.json)。本探针没有导入 CUDA、加载模型或真的越界占卡；既往模型实验未设置该 mask，保存的实际选择快照仍有效。

目标：在可见集合内按启动时实际余量选择；空集合/禁用/无余量明确拒绝，不越界，也不静默 CPU 回退。支持索引/UUID、单卡同组限制与 ASR 入口复用，模拟正反例覆盖后再用显式单卡 mask 实跑核对。用户曾说 6–7 只是当时有余量，不把它固定为永久卡号；显式 mask 与动态头寸是两个都要满足的约束。
