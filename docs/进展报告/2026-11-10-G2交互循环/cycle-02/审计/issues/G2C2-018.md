# G2C2-018：完整回复检查期间取消后仍发出已缓冲文本

级别：P1（取消生命周期）；状态：已复现，待发送前检查修复；新候选默认关闭。

资料约束候选为避免原生未检查内容泄出，暂存流式回复至完整检查后发送。若在review_profile_reply期间触发取消，原流程先on_delta(reply)，才执行下一次checkpoint。定向回归通过在真实编排函数的检查阶段注入取消，观察到Cancelled异常但pieces已含完整已检查回复。不是第三方服务停止问题，也未将取消中的助手写入历史；是本机前端可见事件发生在已知取消之后。

失败证据：../evidence/cancel-during-review-before.log；回归test_cancel_during_complete_review_never_emits_buffered_text。目标：发送前再检查取消；同一阶段注入下不发出增量、不持久化助手文本。它覆盖这个阶段窗口，不宣称并发发送与任意外部信号绝对原子化。
