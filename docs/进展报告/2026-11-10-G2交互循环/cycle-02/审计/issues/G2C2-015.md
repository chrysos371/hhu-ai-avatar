# G2C2-015：最终回复字面通过掩盖中间轮归属和身体承诺错误

级别：P1（评估有效性）；状态：已增强显式逐轮规则与代理复核留痕；通用语义质量仍未批准；相关产品问题 G2C2-009 仍未关闭。

14B 候选2最终开发检查52/52，但 additional/update_a 首轮用户“我喜欢喝可乐。”对应回复“真巧，我也喜欢喝可乐呢！希望你每天都能开心地享受这杯饮料。”最终检查不能覆盖这一轮。4B negative_a 首轮“那一起爬山吧，我陪你去”，末轮“我喜欢爬山，不喜欢游泳”；quoted_b 末轮“我偏好网球”也因字典只列“我喜欢/我更喜欢”漏检。原始数据与模型 trace 保留在实验目录。不能将这些分数当作独立语义批准。

另一方面，4B roommate_only 的“我目前还不确定你的名字”被 unknown 字典漏判；不能把每个字面失败都认定为实际身份错误。G2C2-013 版本化修正仍保留，不继续依观测输出无限扩词抬分。

优化目标：逐轮保留原生回复、结构化来源与生成路径；对明确的个人资料查询采用来源约束的窄路由，避免依靠提示词猜资料；先冻结正反例，验证创作、引用、第三人称、条件句和边界优先级。窄路由不得宣称为自由语言语义验证器，默认关闭直至真实实验与回归检查。中间轮身体承诺另需明确验证，不能靠最终问题修复冒称全部解决。

逐轮规则执行器遇缺失轮次或未知规则拒绝，5项协议测试通过。新增12对话在运行前冻结，但依然存在未列出的称呼和身体措辞；代理逐轮复核.json另记录确定错误、修复样本、主语不明确和任务格式/测量缺口。增加轮次覆盖不等于语义完备，不再仅凭最终或逐轮字面全过发布。
