# G2C2-001：口型分析下采样缺少抗混叠滤波

级别：P2；状态：已修复，专项复测通过。

## 现状与证据

SpeechService 对大于 16kHz 的 PCM 用 np.interp 缩到 16kHz，未先低通。隔离的 probe_audio.py 经真实服务截获送入分析器的样本：48kHz 的 14kHz 单音折叠为 2kHz，保留约 99.97% RMS（-0.003dB）；24kHz 的 10kHz 输入仍保留 -2.73dB。它们均高于目标 Nyquist 8kHz，却污染分析频带。2kHz 对照基本保留。

原始数据：[audio-audit-before.json](../evidence/audio-audit-before.json)。这证明信号链缺陷，不据此声称真实元音准确率已受损多少。

## 优化目标与预设验收

增加核心 NumPy 可用的低通抗混叠下采样，保持时长、起始对齐、可取消。相同 24/48kHz 探针高频抑制至少 40dB，2kHz 通带误差不超过 1dB；静音、有限值、短音频与原服务流程回归。真实中文分类增益另需独立标注实验。

## 修复与复测

增加零相位窗化 sinc 低通，再按目标时钟取样；分块卷积支持取消，不新增 scipy 核心依赖。同输入：48kHz/14kHz 高频增益 -78.02dB，24kHz/10kHz 为 -70.84dB；2kHz 通带误差最大 0.150dB，满足原门槛。起始对齐/静音/短音频/中途取消及语音专项共 18 passed。结果见 [audio-after-filter.json](../evidence/audio-after-filter.json)，该中间结果来自提交前工作树，最终审计另附源码哈希。真实元音分类增益仍未验证。
