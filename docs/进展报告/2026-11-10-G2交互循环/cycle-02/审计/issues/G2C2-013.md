# G2C2-013：字面评估遗漏产品明确允许的未知表达

级别：P2（评测正确性）；状态：已复现，待版本化修正。

原 no_fact 的 any 字典没有“不记得/无法确认”，而早于本轮实验的 _system_prompt 明确要求记忆缺失时使用“目前不记得或无法确认”。14B 输出“我目前不记得你提到过自己所在的大学……”语义符合该要求，却被原字面检查判失败。见 [原始证据](../evidence/unknown-oracle-before.json)。这不能当成真实模型错误，也不能把字面命中当完整语义批准。

目标：保留原冻结题目、v1 分数和原始回复不变；新增带版本与更改理由的评价规则，区分原门槛结果和依据既有产品规范的修正统计。已知输出上的重评分不宣称独立验收。后续新冻结场景同时验证真实归属错误与未知表达，不以词表修复掩盖 unknown_self 的真实错误，候选仍保持默认关闭。
