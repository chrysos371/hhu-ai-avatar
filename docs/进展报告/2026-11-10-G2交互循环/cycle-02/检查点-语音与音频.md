## 失败、资源与数据来源

一次额外复测沿用旧 GPU 0 快照，随后占用变化造成 OOM，失败已保留。入口已改为启动时采样余量、尊重显式可见掩码；真实模型联合测试要求同组。最新正向测试实际发现 0–3 满载、4–7 空闲，自动选 GPU 4，余量 40438MiB，未终止他人进程。识别实验先前选 GPU 0 时也保存了当时空闲快照；不把任意一次卡号或空闲状态当永久资源分配。

AISHELL-1 上游 [OpenSLR SLR33](https://www.openslr.org/33/) 标明 Apache-2.0。镜像 [shenyunhang/AISHELL-1](https://huggingface.co/datasets/shenyunhang/AISHELL-1) 固定 2724409d538167445e43ebf846990319f12a1cbf；抽样先于识别。音频不入 Git，参考文本/路径/哈希在 [清单](实验/aishell-manifest.json)。不因识别失败替换样本或事后改数字归一化。

真实模型使用 [Qwen 官方 GGUF](https://huggingface.co/Qwen/Qwen3-4B-GGUF) 固定 bc640142c66e1fdd12af0bd68f40445458f3869b、Q4_K_M。权重 2497280256 字节，SHA256 与官方 LFS oid 一致，见 [核验](实验/gguf-verified.json)。官方 llama-cpp-python 0.3.19/cu124 wheel 下载中；同配置 20 场景已冻结于 evals/interaction/cycle-02/real-model-cases.json。依赖未准备好前没有实际 4B 分数，没有借受控输出冒充模型结果。
