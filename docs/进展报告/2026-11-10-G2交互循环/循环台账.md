# G2 交互推进循环台账

作者：spinner-bot。基线：c89b93e。用户要求持续推进、代际提升后系统审计、完善后进入下一循环；所有结论须有实验数据。

## 循环规则

每轮按“预设指标 → 实现 → 同条件实验 → 系统审计 → 单项修复 → 重测 → 下一轮”执行。实验原始输入、输出、版本、环境与脚本形成证据链。测试通过数仅作工程覆盖，不作为模型质量或用户体验的替代指标。未通过门槛或未测项目必须标为未验证，不能修改门槛来追认结果。

## 资源决策

GPU 按实时显存和计算负载选择，不固定卡号。当前 0–5 几乎无显存余量，6–7 约有 31 GiB 余量且已有进程，用户明确可按实际余量使用。首轮只使用一张卡、单个小模型、batch=1；记录运行前后状态，不终止他人进程。后续最多同组四张，先测后扩大。不设置实验墙钟截止，保留预设样本数、算法轮数与早停规则。
