# C42-001 缺少编号的状态问题仍被错误路由到政策

优先级 P2；状态开放；范围为隔离实验候选，默认产品未启用。2026-11-14，spinner-bot。

当前用户问“我之前设的那条提醒现在是什么状态？”时，没有唯一可绑定的编号。eligible_complete 目录提供政策读取与显式澄清两个动作，模型仍在三次重复中均选择 read_reminder_delivery_policy({})。执行和固定渲染都符合有限参数门槛，资料也真实，但未回答所问；按预登记结果三次均错。

## 审计结论

目录过滤解决了 policy-exit 中虚构12345编号的不可执行工具选择，但有限参数合法性不能证明语义相关性。新增澄清动作只让另一题 missing-reference-number 三次选择正确澄清，未解决本题。只展示一个政策工具的消融在两个缺参诊断上都错，不可推广。
