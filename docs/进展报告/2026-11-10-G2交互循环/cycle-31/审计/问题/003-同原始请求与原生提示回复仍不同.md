# C31-003 同原始请求与原生提示回复仍不同

P2/研究可复现与归因，状态开放。32B材料题三轮中，两臂第三生成的原始SDK JSON逐字相同、request SHA一致、native prompt SHA一致，固定temperature0/seed42等配置相同，但原路径回复93，省略认知调用路径回复37 + 46 = 83。原生call ID/完整wire与评测SHA另存并独立绑定。

不同的是请求前序路径（是否先有认知调用）；不能由此直接断言根因为KV缓存、数值精度或某个库错误，也不能把同prompt当作足够的输出一致保证。原方案严格逐字门槛正确失败，数值不同未自动解释成候选退步；测得的局部耗时仍是给定状态下真实观察，不泛化为固定模型的纯速度或语义机制效应。

优化目标：后续另登记相同请求、受控前序/状态重置/重放的原生提供方实验，记录真实输入/配置、原生实现身份和状态策略，再确定可复现比较契约。当前325与原8任务不修改，不靠重跑挑93或83的期望输出。
