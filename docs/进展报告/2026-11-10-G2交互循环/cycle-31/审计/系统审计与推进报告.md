## 实现、保护与实验来源

当前产品Web已有保守科普fast_analysis，本轮候选只在显式审计worker委托Avatar._analyze。它限制现实scope/无进行中边界风险、单个显式资料问句、当前/最近六条词表情绪为0、无当前规则事实；不合格调用原方法，合格仍执行真实_extract_facts和取消/隐私检查，再用规则情绪更新。没有修改src/tests/scripts、用户提示、生成schema或默认产品开关。

48预登记CPU shadow（12合格/36保护）首跑全过；进程内真实Web+明确假模型的8双臂控制保留姓名源5、最近非中性情绪和角色权限；另有独立MemoryStore遗忘交错在真实版本屏障取消，0额外模型调用/无新助手。它们不是实际LLM/GPU或独立OS数据。真实HTTP计时校准证明源指纹检查、终态后conversation读取及审计写盘在端点之外。

两模型真实144回合/96OS/272原生数据分别独立绑定325历史Git与当前源、原始SDK字节/response schema/native trace、SQL/API稳定ID、SSE、实际模块、72候选路由决定和单调时钟整数；SQL全表导出重建一致。两保护的全部18个turn/模型用户情绪/策略/风格相同，姓名画像/事实一致。所有288回复做same-agent来源span审阅，不等于独立真人标注。

## 推进优先级

本轮325输入已完成退休并保留失败推广门槛，原8任务/提示不再调优，候选保持隔离。下一循环优先原生提供方相同请求的前序/状态隔离复现性；只有先建立比较契约，才继续含蓄情绪的模型影响及候选修订。不自动更换默认模型、不启旧v1–v4或C28固定计划机制。

| 优先级 | 工作 | 完成证据 |
| --- | --- | --- |
| P1长期开放 | 一般能力/回执诚实性、归属/任务质量 | 真实来源与逐轮审查；既有失败不因局部性能改善关闭 |
| P2当前首要 | 原生同请求/不同前序的状态隔离 | 先登记受控前序/重置/重复、wire与实现身份，区分实测机制与推测 |
| P2 | 含蓄情绪与语义中性保护 | 独立源/实际模型反例，不能仅把词表0作为批准证据 |
| P2 | 数值推导与严格格式 | 新来源任务和只读计算证据，内容正确与输出形式分开 |
| P2 | 设备/真人/正式形象与多日 | 真实来源、目标设备和长期事件记录；合成与短测不替代 |
