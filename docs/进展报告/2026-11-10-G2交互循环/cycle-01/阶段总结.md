# Cycle 01：G2 交互评估与系统审计结论

作者：spinner-bot。基线 c89b93e；最终实验来源版本与哈希见原始结果。状态：**预设的交互工程门槛通过；9 项已复现审计问题完成修复与复测，进入 Cycle 02。**

## 能力变化

网页已从同步返回、手动整段朗读，推进到有请求去重与生命周期的流式回合：逐句检查草稿、最终确认替换、生成中断、自动分段语音与最多一段预取、麦克风打断，以及真实本机 CPU/GPU ASR。模型输出半成品不会存入助手历史或先行朗读。识别文本仍先进入草稿，发送是明确操作。

## 预设门槛与实测

| 指标 | 审计后数据 | 结论范围 |
|---|---|---|
| 首个已检查输出 | 同服务/同输入/10 次交替对照：738.6ms → 93.6ms，比 0.1267 | 限定知识问题的可控传输实验，通过 50% 门槛；个人/情绪场景保留原分析，不外推真实模型质量 |
| 中断 | 20 次受控连接实验，等待响应头/接收流式，本机取消 p95 2.48ms | 证明本机任务/连接退出，不能证明第三方计算或计费停止 |
| 首段可播 | 真实 TTS 三对，整段中位 7.842s，首段 3.075s，比 0.3922 | 通过 70% 中位门槛，网络波动显著；初轮曾出现首段更慢，不保证逐次收益 |
| 真实 ASR | 12 干净+12 噪声+3 静音。CPU CER 0；GPU 干净 CER 0.00556、噪声 CER 0；静音均为空 | 合成开发语料通过 20% 门槛，不代表真实人声/物理麦克风准确率 |
| ASR 速度与资源 | CPU int8 中位 1.468s，GPU int8_float16 中位 0.187s；配置整体比 7.86，采样最大显存 852MiB | 两配置量化类型不同，不能把差异全部归于 GPU；运行前后快照与采样数均留存 |
| 浏览器整合 | 真实 GPU ASR → 草稿确认 → 可控模型流式回复 → 真实 TTS → Chromium/SVG：1 passed | 草稿可见约 916ms，发送至实际播放约 5039ms；真实 LLM 质量与物理麦克风未验证 |
| 工程回归 | Python 638 passed/1 skipped；前端 28 passed；类型/lint/构建通过；浏览器 12 passed/1 可选真实服务用例跳过 | 可选真实服务用例已另行显式实跑通过；测试数不作为陪伴质量得分 |

GPU 的唯一干净字符差异是“三点”写成“3点”，仍按预先固定的字符规则计差异，没有事后改为零误差。GPU 6 运行前有约 39.5GiB 余量；仅用一张卡，运行后显存已释放。GPU 按实际余量选择，没有固定卡号限制。
