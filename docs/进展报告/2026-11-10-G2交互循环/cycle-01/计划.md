# Cycle 01：G2 交互候选

## 对照基线与预设门槛

基线 c89b93e 是请求返回式文本与手动整段朗读；真实 TTS/最小 SVG 已验证，真实 ASR 未验证。

| 指标 | 实验 | 预设门槛与结论边界 |
|---|---|---|
| 首次可见输出 | 同一个可控本机 OpenAI 兼容流式服务，逐段延迟固定、相同输入，重复至少 10 次 | 流式首个已检查片段先于最终回复；中位等待不超过完整等待 50%。仅证明传输/编排收益，不外推真实模型 |
| 中断与一致性 | 分析/生成/合成中断、迟到回调、重复请求，包含实际 HTTP | 本机上游连接关闭与界面停止可验证；受控场景 p95 <500ms；不持久化半截助手回复、每个请求最多一次用户写入 |
| 首段语音 | 同一长回复，整段 vs 分段，真实 Edge-TTS 至少 3 对，记录顺序与原始耗时 | 首段可播中位等待不超过整段 70%；若网络波动或结果未过门槛，保留失败与待优化状态 |
| 本机识别 | 固定中文脚本 × 两个 TTS 音色，共 12 条干净语音，叠加固定种子 20dB 噪声再测，另加 3 条静音 | 干净合成语音 CER≤20%，静音不自动发送；不能据此声称真实人声/物理麦克风准确率达标 |
| 工程与审计 | 全量 Python、前端、浏览器；鉴权/取消/资源/记忆/安全/依赖/文档七个维度 | 无未关闭的新增 P0/P1；逐问题有证据、修复和回归，剩余风险单列 |

## 实施约定

- 保留已确认用户发送的事实；中断生成不撤销已明确执行的用户操作。半截模型输出不进入记忆。
- 对外只发送经过边界检查的句段，最终回复仍经完整检查；语音仅使用最终检查后的文本，避免未定稿内容先播出。
- 任务有明确生命周期、请求幂等、并发上限与清理；浏览器令牌不进入 URL。
- 对模型与网络取消只能证明本机任务/连接已停止，不能假定第三方服务器已停止计费或推理。
- 每个结论附可复现脚本与原始结果；缺少真实模型、GPU 余量变化等条件时继续独立工作并如实留痕。

## 接口依据

流式接口遵循 [官方 OpenAI Streaming 文档](https://developers.openai.com/api/docs/guides/streaming-responses)，本机安装的 SDK Stream.close 直接关闭 HTTP response。识别候选参考 [faster-whisper 官方仓库](https://github.com/SYSTRAN/faster-whisper)，模型与依赖须记录版本和哈希。
