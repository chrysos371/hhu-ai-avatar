## 事件驱动任务生命周期

- 新增有界对话任务、受鉴权的 SSE 事件、取消接口与持久请求编号账本。相同编号/消息重复提交复用同一个任务；重启或记录淘汰后也不会自动重放旧请求。
- 串行共享会话状态，取消排队时可退出；终态事件发布前释放任务容量，避免客户端收到完成后立即发送被误判为忙。
- 任务重用既有边界、记忆、提醒和来源轨迹；保留已确认用户输入，半截助手回复不写入。流式进度不会提前朗读。
- 实际 HTTP 验证鉴权、事件流、20 次重复请求仅执行一次、进程重建后拒绝重放、取消后容量恢复，以及原 Web API：**15 passed**（与上组为同一专项，非新增累计）。

## 真实 GPU 对照与浏览器语音链路
