# G2-006：流式读超时不等于整次请求时限

优先级：P2。状态：已修复，专项与原探针复测通过。

## 现状与实验数据

配置 0.15 秒超时，可控服务持续分块，调用 1.494 秒后正常完成，没有触发总时限。

完整原始记录见 [审计探针结果](../evidence/audit-before.json)。

## 审计结论

每次块到达会刷新读超时；对持续慢流无法限制整次上游调用。

## 优化目标与复测

为 async 流式分析/回复增加总时限；真实 HTTP 复测持续分块也能退出并关闭连接。

## 工作记录

- 登记：保留失败数据后建立本项文档；实现与复测结果后续追加。

## 修复与验证

在异步任务外增加总时限，覆盖不断到达的小块与清理网络连接；统一 Python 3.10 的 asyncio.TimeoutError 与内建 TimeoutError。0.15 秒探针实际 1.494 → 0.152 秒，异常 TimeoutError；流式/语音取消专项 8 passed。
