# G2-008：单个事件订阅断连取消其他存活订阅

优先级：P2。状态：已修复，最终回归与审计探针通过。

## 现状与实验数据

同一任务建立两个真实 HTTP 事件订阅，主动断开第一个，第二个收到 cancelled 而非 result，最终状态 cancelled。

原始 [协议探针](../evidence/audit-subscriber-before.json)。

## 审计结论与优化目标

按存活订阅数判断是否取消，单个断连不影响其他已建立订阅；最后一个订阅断开时仍能停止任务。

## 修复与验证

断连时先更新存活订阅数量；只有最后一个订阅离开且任务仍未终止才取消。真实双 HTTP 订阅回归 **1 passed**，断开一方后存活方收到 result、任务 completed。完整协议探针将在 G2-009 修复后复测。
