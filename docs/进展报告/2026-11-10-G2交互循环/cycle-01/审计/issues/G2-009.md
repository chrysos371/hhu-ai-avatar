# G2-009：超前事件游标返回空的成功响应

优先级：P2。状态：已修复，最终回归与审计探针通过。

## 现状与实验数据

对有事件的完成任务请求 after=9999，返回 HTTP 200 且响应为空，客户端无法区分游标错误与丢失结果。

原始 [协议探针](../evidence/audit-subscriber-before.json)。

## 审计结论与优化目标

校验游标格式、范围和重复参数；超前游标明确 422，合法末游标和从头重放保持可用。

## 修复与验证

游标范围在订阅前校验，非法/超前/重复/空值和未知查询参数明确 422；合法从头重放仍返回结果。真实 HTTP 双订阅与游标专项 **2 passed**。原探针超前游标 **200/空响应 → 422/错误 JSON**；双订阅则 result/completed，见 [最终协议探针](../evidence/audit-protocol-final.json)。

最终放行数据：[audit-release.json](../evidence/audit-release.json)。
