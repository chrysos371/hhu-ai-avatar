# G2C8-001：迟到媒体事件能覆盖当前播放器状态

P1，受控异步事件队列复现范围。useSpeechPlayer回调未核对当前audio状态：已停止且src移除后旧play能把状态复活为playing；实际仍播放时旧pause能关闭显示；ended=false的旧结束事件可提前消费预取片段；error=null的旧错误事件可释放健康新src。冻结7项：4个迟到/状态不一致例与3个真实状态对照。

这不等于已测得浏览器自然发生此竞争的频率。修复目标是事件处理服从当前媒体src、paused、ended、error状态，保持真实暂停/继续/结束/解码错误行为；通过实际Chromium时钟/切段对照和既有端到端回归验证。
