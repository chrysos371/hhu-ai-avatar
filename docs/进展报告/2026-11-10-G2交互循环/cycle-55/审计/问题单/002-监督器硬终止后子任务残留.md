# C55-002 监督器硬终止后子任务残留

优先级P1；状态OPEN，实际CPU复现。

[故障实测](../工作目录/006-托管故障补充审计/parent-death-v1.json)：监督器接收SIGKILL后身份消失，实际子任务身份仍活，原status保持running/return_code=null；不能从该status推断成功。该问题与短启动器退出不同，也不推翻正常SIGTERM转发控制。自建无关CPU对照仍活，残留仅按本fixture PID/start_ticks/argv和独立进程组核验后清理。原监督器不可wait，退出码未知，原文件未伪造改写。0模型/GPU，不模拟主机断电，不触碰当前old_adapter。

影响：监督器自身被硬杀时，独立会话工作进程可能继续占用资源，而无人取得实际终态。C55新增的终态门禁仍会拒绝推进，但资源自动退役未解决。

优化目标：在下轮为直接工作子进程登记Linux父进程死亡信号保护，并关闭设置与父死亡间的竞态；保持正常独立启动、退出码、停止转发、无自动重试和不设整轮墙钟截止。先CPU控制复现红→修后绿，实际身份/清理证明和负控齐全，再推广；不改正在执行的534冻结输入。内核保护不能恢复丢失的原父wait退出码，此时仍应明确终态未知/实验失败退役，不冒称断电持久化或整棵任意孙进程树已解决。
