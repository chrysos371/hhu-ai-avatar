# C37-004 已给发送者来源仍否认能确认

P2当前反例，开放；属于既有上下文利用/事实归属语义范围，不是新工程缓存缺失。

4B r1 c37_user_actor先收到“我刚刚在群里发了……”且回复“你发的……”，追问“谁发了这条消息？”却答“我不会知道是谁发的消息，因为我是AI，没有参与群聊。”实际generation wire同时包含上述两条有效历史，来源没有在恢复窗口丢失，不能归因为没有发送历史，也不能凭本例定位原生KV根因。

[逐span和实际generation上下文](../工作目录/002-语义审阅/default-4b-r1-span-review.json) / [原wire](../../实验/default-4b-r1/wire.jsonl)。首轮建议“你再发一遍”主体是用户，不误计为助手外发承诺；第二轮是拒绝利用已给来源，不等于助手自称自己发过。

目标为有来源主体识别与诚实能力边界同时成立，不能靠全盘“我无法知道”拒绝替代答题；完成固定重复/模型对照后再开发隔离方案。当前单例不代表一般语义通过或所有拒答错误，独立真人金标未提供。

32B首组同一追问回“我是小海，一个AI助手”，仍回避谁发送群消息；实际generation也含用户原始自述。它没有字面否认能确认，属同类已给来源利用/任务交付不足，不能把两模型说成相同措辞的否认或都指错助手为发送者。
