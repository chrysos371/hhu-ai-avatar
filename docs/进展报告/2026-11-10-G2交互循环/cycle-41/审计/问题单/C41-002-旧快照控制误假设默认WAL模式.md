# C41-002 旧快照控制误假设默认WAL模式

状态：限定关闭；优先级P3；并发测试设置。

实际MemoryStore默认SQLite rollback journal；调用方持有读事务时另连接forget写入无法完成commit，首控制报database is locked。首轮其它64控制通过；此例尚不能证明旧快照中已完成隐私写入，也未观察到泄漏。[首log](../工作目录/001-来源与参数调查/service-first.log)。

针对旧读快照遮蔽已完成外部写入的控制，应仅在该独立测试库显式启用并记录WAL，保证外部forget确已提交，再验证publish拒绝持有事务及释放后旧epoch取消。另增加默认rollback journal正控：持读时writer被锁/不推进版本，释放后forget成功且旧结果不能发布。产品journal设置不改，不把配置假设当产品问题。
