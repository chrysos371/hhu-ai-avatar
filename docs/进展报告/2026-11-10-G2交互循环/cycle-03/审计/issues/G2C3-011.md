# G2C3-011：过宽改稿前缀把新问题和寒暄绑到旧任务

P1，24项预冻结检查12过12败。写作后用户说“再问个问题，什么是重力”“不用谢”“还是说说二进制”“只要你陪我聊天”，旧continuation把“再/不用/还是/只要”直接当改稿。交付检查随后会试图把普通回答修正成带旧原文的写作产物。

目标：只保留有明确编辑谓词的跟进，新的提问/解释/寒暄/话题切换释放旧约束；“再短点、润色这条、改成、保留、删除”等控制组仍连续。不是通用意图理解，也不保证任意多意图自然语言解析。

改为明确编辑谓词跟进；提问、解释、寒暄、取消/换话题释放旧状态，非文字对象的“修改”不再继承写作合同。原24项、取消后同回合新任务、网页实例间新问题与既有回归共101项通过（详情见web-after.log）。源窗口原文仍可用于普通对话，不再对新问题强塞旧字面。
