# G2C3-004：任务修正调用不可即时取消且吞掉Cancelled

P1，已修复，同一取消令牌用于SDK修正调用。初稿走可取消stream_chat，而修正仍走同步chat，不能共享回合取消；修正阶段except Exception还捕获自定义Cancelled，可能继续交付已知不合格草稿。

最小测试在修正阶段抛Cancelled且不修改token，respond并未传播异常，测试失败。目标：存在cancel并具备流式接口时，修正也走同一可取消传输，期间不发增量；Cancelled单独传播，最多修正一次。使用实际SDK/受控本机HTTP补待响应头阶段取消与连接关闭证据。

修正现在在可用时走stream_chat，on_delta=None，并单独传播Cancelled；原有无流式模型和无取消令牌的同步兼容路径保留。SDK负向回归首次因测试把SQLite连接跨线程使用而失败（不是生产并发缺陷），保留after.log；改为与生产一致的worker内创建/关闭连接后，31项关联测试通过，含待响应头阶段真实断开、无增量和无助手落库。
