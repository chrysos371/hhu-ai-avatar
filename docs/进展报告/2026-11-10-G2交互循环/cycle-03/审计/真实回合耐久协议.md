# 真实模型100回合HTTP/SSE耐久协议

先冻结evals/interaction/cycle-03/real-turn-soak100.json，后实现与执行。所有数据库临时隔离，模型使用本机已核验4B；不是生产用户数据。

每10回合循环一次：受约束文案、明确改稿、新知识问题、唯一测试昵称、自身资料回忆、可选删除后的回忆、写提醒文字、授权创建本机提醒、知识问题、观察到真实模型首个原生片段后取消。第45/95轮之后用独立SQLite连接删除来源，检查已发结果与派生副本失效。每块验证一次重复请求不再执行，真实提醒总数应为10。

固定100回合；首个硬性协议/隐私/重复副作用/状态失配失败即算法早停，保存部分结果，不重试抹除故障。每个HTTP/模型调用保留正常网络超时；没有实验总墙钟截止。取消必须观察真实模型回复流启动，不能把排队前取消冒称实际上游停止。

每10轮保存CPU进程RSS、FD、线程数、缓存和SQLite完整性；取消记录HTTP端到端时延与真实提供方client_disconnected。只结论于本次短时运行；没有测试多日运行、物理设备、听感、通用事实或陪伴质量。采集器会保留公开合成昵称/输出用于审计，其日志不属于应用记忆删除承诺的范围。
