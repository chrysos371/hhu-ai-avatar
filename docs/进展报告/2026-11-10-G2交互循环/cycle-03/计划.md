# Cycle 03：可信回复判定与交付约束

基线3194161；作者spinner-bot。本轮续接第二轮009/016等开放问题，不表示上一轮所有质量已验收。

1. 先验证判定方法：冻结40条来源/角色/身体边界复核输入，开发16条、预先保留验证24条，包含明确违例、明确合规、必须保留不确定的歧义。4B/14B同配置分类；严格JSON和逐字证据，只给模型初审，不自动发布。
2. 只有判定准确性与服务失败行为先通过，才考虑接入回复修复。当前生产Verifier仍未配置。保留全部错误、无效输出和延迟，不用新词表或改标签追认效果；保留验证运行后即失去未见身份。
3. 为可执行任务约束补格式/字面交付的正反例和有界修复，创作第一人称不得误判为角色身体；已开启交付修复的流式路径要检查修正前文本是否提前流出。
4. 结合结果进行系统审计，逐项文档、失败复现、修复和回归；保留MD/HTML及实验原始输出。固定样本/轮数和网络超时，不设置实验墙钟截止。

资源：每次按真实余量与显式可见集合选择，最多同组四卡；模型与测试库隔离，不改生产配置/记忆，不结束他人进程。每项工作小步提交；作者统一spinner-bot，使用既有SSH路径推送。
