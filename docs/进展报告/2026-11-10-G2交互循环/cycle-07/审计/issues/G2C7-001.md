# G2C7-001：名义毫秒时间与实际整数样本跳步产生累积漂移

P1（软件音画时间轴），已实测。frame_signal使用int(sr*hop_ms/1000)样本，LipSyncEngine却按hop_ms输出时间。固定22例9过/13败；22050Hz默认10ms、120秒零PCM输出末帧120.24秒，而对应实际样本119.9673469秒，漂移272.653毫秒，甚至落到音频结束后。不是物理设备延迟测量。

目标：用实际整数hop样本/sr计算帧起点；不改变帧数、开口、元音、能量，整数hop保留旧时间；文件TTS API也验证。第六轮相对旧输出等价结论按原源码留存，这一绝对时钟修复独立版本化，不追改旧证据。
