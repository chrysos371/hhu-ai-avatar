# G2C6-001：补峰总分提高仍把未知变成错误确定标签

P1，候选问题，未接默认。固定开发4臂：roots400组件增加12个退步场景、网页16个；dense10分别4/2个；fallback50无既有场景退步且网页补齐，但组件将2个原未知帧改判错误。它们是同一o锚48k白噪声、两档幅度的0.19秒，旧F1=610.57Hz、新F1=597.12Hz/F2=1025.59Hz，跨过原分类器F1决策区。

原选择全部失败，不打开新80信号。下一开发修订只增加“F1决策区一致”保守门槛，沿用当前分类器500/1500/2500Hz的F2探针检查，不改标签或新验证网格。已知数据重分析不叫新验证，需实际组件回放和封存数据验收；即使通过仅开放组件opt-in，不默认替换。
