# 第九轮系统审计与推进报告

日期：2026-11-11（上海时间）。作者：spinner-bot。生产基线776777c。远期目标保持active。

## 本轮结果

口型逐帧数据现由每个播放器的单帧通道发布，仅形象子组件订阅；播放控制、请求取消、分段队列继续由原Hook管理。受控60帧使聊天父树重复渲染的问题已修复。三个模拟历史规模的父渲染从60次降至0，历史访问从60/1500/6000降至0；实际PCM浏览器固定三轮各3项通过。
这些结果支持渲染结构优化与本机控制层回归通过。没有测得CPU加速倍数，没有据此宣布整体代际跃迁、真人音素/物理音画或通用语义质量验收。

## 实际PCM与媒体时钟

沿用第八轮800个10ms唯一开口码、实际Chromium PCM解码与SVG几何检查。每场景48个RAF，保留所有样本，预先剔除2个预热及暂停/结束/seek状态；有效样本至少30。绝对媒体时间滞后p95≤50ms、最大≤100ms，门槛未改。另覆盖暂停闭口、自然结束、停止、完整三段顺序以及预取停止后受控注入迟到play和旧请求完成。
三次是预先固定的同机观察；语音响应由冻结时间轴夹具提供，实际音频播放是真实执行，不能当真实模型、Edge-TTS听感、显示器/扬声器物理同步实验。

## 生命周期与系统性审计

| 方面 | 本轮证据与结论 | 范围限制 |
| --- | --- | --- |
| 渲染边界 | 180次逐帧更新不再渲染父/历史；值全部正确 | 模拟历史，完整页面长负载另测 |
| 快照一致性 | 输入复制冻结、同值引用稳定、四字段变化通知、null去重 | 每实例仅当前帧，不缓存音频/帧历史 |
| 订阅隔离 | 退订后无通知，两个播放器互不影响，1000次更新验证 | 不是多日堆泄漏测量 |
| 清理 | StrictMode暂停/恢复/卸载关闭口型、取消RAF、释放src/URL | 控制事件与本机浏览器场景 |
| 请求与媒体 | 原12项播放器/旧事件回归、实际预取停止均通过 | 仍只预取下一段，未更换后端或模型 |
| 记忆/实际操作 | 本轮未改Python业务，相关服务24项通过 | 一般生成身体边界与模板充分性仍开放 |
| 文档/证据 | 原始失败、各轮数据、源/服务包哈希、MD/HTML留存 | 首次after数据的HEAD仅工作基线，见下文 |

快照及退订约定参考[React官方useSyncExternalStore文档](https://react.dev/reference/react/useSyncExternalStore)：未变化时快照引用稳定，变化后返回不可变快照，并提供退订函数。项目继续固定React19.1.1，参考页当前19.3；本轮没有升级依赖。结构性结论来自本地数据，不由文档替代实测。
