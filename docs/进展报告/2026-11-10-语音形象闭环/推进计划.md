# 语音与最小角色形象推进计划

日期：2026-11-10；起点：`c488008`。作者：spinner-bot。

## 决策依据

既有文本后台、记忆、情绪、管理台已集成；11 项审计整改已有独立记录。下一瓶颈是用户无法在网页听到并看到角色回应。依照 AGENTS.md 和项目进度，优先打通语音播放、音画同步和输入，训练与大型渲染框架后置。

## 本轮里程碑

1. 独立语音输出接口：回复文本先交付；用户主动朗读后生成语音，不因 TTS 故障丢失文本。音频临时保存、鉴权读取、容量与时长约束、超时与失败提示。
2. 网页播放与停止：支持重播，切换回复和离开页面时停止旧音频；令牌不放入音频 URL。
3. 最小浏览器形象：SVG 参数化绘制，按真实 audio.currentTime 查找口型帧，暂停、停止、结束时闭嘴；情绪映射保留可解释性。
4. 可选输入：浏览器采集单声道 WAV，文件识别与麦克风共用转写接口；识别结果进入文本框，由用户发送，避免转写错误自动触发操作。未启用 ASR 时显示明确状态。
5. 可重复验证：Python 服务回归、前端类型/lint/组件与浏览器用例，真实 TTS 探测单列证据；不把合成样本当真实服务验收。

## 版本与留痕

所有本轮提交使用 spinner-bot，按独立功能和验证结果提交。实现记录写入进展.md；最终形成 Markdown 汇总与 HTML 汇报。测试仅使用临时数据库，运行音频不入版本库，保留验证命令和结果。

## 验收边界

本轮采用浏览器 SVG 最小形象，不代表 Live2D/Godot 完成。ASR 必须由本机明确配置后启用；不下载大模型、不占 GPU。真实服务不可达时完成可自动验证的链路，并如实记录外部依赖限制。
