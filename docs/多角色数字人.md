# 多角色数字人原型

入口：管理台左侧「角色馆」，路径 `/characters`。仍使用原来的本机管理令牌，不开放公网。

## 已可试用

- 14 张角色卡：DeepSeek、GPT、Gemini、Claude、Qwen、Kimi、Grok、GLM、MiniMax、Seed、Llama、Mistral、混元、MiMo。
- 已导入 8 套原档案实际存在的立绘预览：DeepSeek、GPT、Gemini、Claude、Qwen、Kimi、Grok、GLM。其余档案列有素材路径但实际请求 404，明确显示立绘待补，文字角色仍可用。
- 每个角色有独立的已确认人设、对话历史、个人事实、情绪和边界状态。切回时恢复原对话；没有自动共享称呼、偏好或其他个人信息。
- 角色卡是本项目编写的初始性格与表达习惯，不冒充画师的官方设定。展开「编辑这个角色的人设」，修改后预览并确认，写入该角色审计；不修改全局或其他角色的人设。
- 所有角色目前共用本地 Qwen3-4B 推理。角色品牌形象不代表调用对应厂商模型，界面展示实际模型名。
- 复用同一大脑、事实校验和安全规则；已确认公共知识可共享，主库私人记忆不共享。明确查询仍走只读工具。

当前是网页中的静态立绘原型。语音、独立音色、眨眼/表情动画、口型与 Live2D 未接入；QQ 的角色选择与头像同步未实现。本轮没有替换 QQ 账号头像、昵称或其现有会话。

## 数据与接口

角色定义在 `src/avatar/characters/catalog.json`，随 Python 包发布。状态默认在项目 `data/characters`：

- `art/`、`art-index.json`、`ART-NOTICE.md`：本地图片、校验值、作者/来源和逐项使用说明；被 gitignore 排除。
- `roles/<id>/persona.db`：独立人设版本、待确认草案和审计。
- `roles/<id>/conversation/memory.db`：独立聊天、事实、运行状态和处理证据。

图片通过鉴权接口以 JPEG 数据提供，不依赖浏览器访问第三方图床。只读角色卡列表不会批量创建所有会话；访问人设或首次聊天才初始化对应角色。

管理 API：`GET /api/v1/characters`；角色下的 `/portrait`、`/history`、`POST /chat`；`/config/persona`、`/config/persona/draft`、`/config/operations/<id>/confirm`、`/config/audit`。角色 id 使用固定白名单；不接受路径、远程图片地址或从浏览器指定底模。

## 2026-11-11 公共对话与可控共享事实

QQ 与角色馆的会话编排已迁入 `avatar.conversation.engine.ConversationService`，旧 `AvatarEngine` 导入保留兼容；网页和该服务均经 `execute_turn` 调用原有 Avatar 核心。网页主库的会话/情绪生命周期仍由网页管理，不迁移生产数据。旧角色会话键及 `qq_*` 表名保留，避免历史断开；这些表名不再代表只能服务 QQ。

角色馆新增「模型配置」「管理跨角色共享事实」「最近一轮处理记录」。模型选择独立保存在每角色 `model.json`，不改人设版本或记忆库。`AVATAR_MODEL_PROFILES` 指向配置文件，格式见 `config/model-profiles.example.json`；密钥只引用环境变量名，管理接口不返回密钥或服务地址。仅列出已配置服务，不代表在线或已通过质量评测。`AVATAR_MODEL_PROFILE` 可选择网页/QQ默认配置，角色馆独立选择。没有自动启动模型、付费调用、自动回退另一供应商或自动上线14B。

每个模型明确声明结构化分析模式（json_schema/json_object/none）、原生工具支持和可选思考开关。思考开关当前适配使用 chat_template_kwargs.enable_thinking 的本地兼容服务，其他供应商需另行适配，不能视为通用协议。能力不支持时明确记下规则降级/工具不支持原因，不重放工具；模型正文中的完整 think 块过滤，未闭合思考内容拒绝作为回复。

统一记录含轮次ID、入口、角色、实际模型与配置、人设版本、召回候选ID、知识来源、策略/边界、工具结果、分析状态、回复降级与耗时。不保存密钥、完整提示或隐藏思考。每库公共记录保留200轮，网页受保护 `GET /api/v1/turn-traces` 返回最近40轮；角色 `GET /api/v1/characters/{id}/traces` 返回最近40轮。召回候选与机械状态不等于语义验收。

共享事实先限于本机角色馆的已鉴权 local-owner：手动填写称呼/饮食/偏好，逐条选择可读取角色；不自动提取、不自动推广、不共享角色关系或共同经历，也不把网页管理主库私人事实复制进来。默认角色列表为空。共享数据只临时注入当前提示，角色自己的事实库与情绪仍隔离。修改、撤销、撤回均有独立操作记录与版本；撤销后下轮重建上下文，历史聊天仍保留供用户查看，已发出的回复不能收回。

尚未实现 QQ 与网页身份绑定，因此不会跨平台共享个人事实。群聊共享也未开放。当前是条目类别与显式授权约束，不是对手动内容的通用语义分类器；用户不应把共同经历填到偏好栏。

查询沿用只读工具白名单；外发消息和外部写入未增加自动执行能力。普通原渠道聊天回复沿用已授权接入，管理修改由用户明确操作，现有高影响管理操作仍走草案确认。
