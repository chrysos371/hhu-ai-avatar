## 工作方式

- 与既有任务技能共用最多一个技能、1800字符预算和context.read权限，不增加工具、联网、文件或发消息权限。
- 正常教学、正式写作优先；严肃倾诉、拒绝玩梗、告别不加载接梗。仅规则识别，不能替代完整语境理解。
- 解释模式按明确词义请求触发；一般“这个函数是什么意思”不会当成梗。引号内命令不触发，明确询问引号里词义可以检索。
- 接梗模式需明确请求或已知表达配合轻松语境；不把一般“芜湖景点”查询当玩梗。
- 最近10条用户消息中的拒绝继续生效，直到用户明确恢复。此限制是窗口内状态，不是跨会话永久偏好承诺；不把词库当用户记忆。
- 只检索实际命中的最多2条；不把整库注入，不硬塞一个无关梗。库内容是资料而非指令，明确离线资料不等于本轮联网。
- trace.skills.retrieval包含mode、词条ID、来源URL和库哈希；技能摘要也覆盖表达库内容，因此词库变化可追溯。
- 未收录词义请求直接说明资料不足；追问首创者/最早出处时，不把词条或新闻当作首发证明。generation_mode=skill_source_guard区分此回应与模型生成。只在启用接梗且正常本地对话路径生效，不替代已授权联网查询或安全规则。

## 2026-11-11实际验证

首批8个场景、每组12轮，共24轮真实本地qwen3-4b-qq；两组基础技能都开启，唯一试验开关是接梗。每组11轮模型回复、1轮安全规则。已保存完整调用消息、参数和人设/源码/技能哈希，没有启用云端评委。

审阅发现：

- 有用的局部变化：关闭组将“蚌埠住了”主要解释为无奈无语；开启组能说明笑、难过和愤怒的语境差异。
- 玩梗效果没有稳定改善：开启组把“哈哈”接成“你真的笑不出来吗”，另有套话、多余建议，庆祝时不一定更自然。
- 倾诉、拒绝后、正式任务及安全场景没有继续加载接梗。两组正式任务都擅自写了请假一天，属于原写作能力问题，不归功或归咎于接梗；生成差异也不能都当成技能收益。
- 对词库未收录的表达，两个模型组仍给出无来源的确定解释。发现后补source_guard，再以真实通道跑未知表达和已知词起源两轮，均走资料校验直出、不调用回复模型。保留原失败，不声称小模型自行学会避免编造。
- 最终合计新跑26轮。不是最终源码把24轮全部新跑一次；最终未知来源相关2轮补跑，其他24条技能选择逐条重放一致，已注入的8个技能提示块与最后代码一致。摘要整合库内容的哈希升级不改变提示文本。
- 首批模型轮中位关闭6.691秒、开启8.060秒，未固定随机种子，共享CPU和缓存会影响时间；不宣称普遍提速或质量净增益。资料校验直出不混入这项模型耗时比较。
- 全量740通过、4跳过。含笑/难过对照、拒绝与恢复、任务优先、引用、普通含义问句、预算、独立开关、来源哈希、未知/最早出处校验及已有鉴权。wheel包含三套技能共13个素材文件。

证据：data/research/banter-ab-20261111、banter-origin-20261111，含完整对话.md、原始turns.jsonl、调用消息/参数、元数据及测试日志。语义结论由同一AI完整阅读，非独立人审、非泛化批准。
