# MCP 助手工具

## 使用

在仓库根目录安装可选扩展（普通聊天仍可不安装）：

```powershell
python -m pip install -r requirements-web.txt
python start_web.py
```

打开启动终端提供的完整链接。在输入框下勾选“允许使用网页、天气、资料和提醒工具”，再发送：

- `帮我搜索 Model Context Protocol Python SDK 官方文档`
- `请读取并总结 https://www.python.org/`
- `/read https://modelcontextprotocol.io/introduction`
- `查一下南京天气`
- `在课程资料里搜索降雨径流`
- `查看我的提醒`

不需要联网时取消勾选。默认不勾选，不会因普通聊天自动连接外部工具。

CLI 支持 `/search 搜索词` 和 `/read 完整链接`。这两种明确指令不依赖模型原生工具选择；未配置模型时也可显示工具直接返回的搜索简述或网页摘录。

界面显示工具的成功/失败状态、是否由模型选择，以及实际返回的来源链接。搜索简述与已读取正文分开标记。失败、限流、验证码不视为成功搜索，也不会用模型猜测冒充搜索结果。

资料查询须先在 `.env` 设置 `AVATAR_DOCUMENT_ROOTS`。Windows 下多个目录用分号分隔；服务只读取白名单目录及子目录里的 UTF-8 `.md`、`.txt`，忽略隐藏文件、符号链接和超过 256KB 的文件。

## 五个只读 MCP 工具

| 工具 | 参数 | 返回 |
|---|---|---|
| `web_search` | `query`，可选 `limit`（1～5，默认3） | 标题、公开链接、简述、查询与时间 |
| `read_webpage` | `url`，可选 `max_chars`（200～8000，默认4000） | 最终URL、标题、正文摘录、是否截断、获取时间 |
| `get_weather` | `location`，可选 `days`（1～7，默认3） | Open-Meteo 当前天气和短期预报 |
| `search_documents` | `query`，可选 `limit`（1～10） | 白名单内相对路径、行号和摘录 |
| `list_reminders` | 无 | SQLite 提醒列表 |

搜索使用 DDGS 多引擎自动选择，无需搜索API密钥，但并无可用性保障；某些查询可能被限流或没有结果。本机搜索和公开页面读取已实测。页面阅读只支持 HTML、文本与 JSON；不执行JavaScript、不登录网站、不下载附件。复杂页面可能只提取到导航或部分正文。

本实现固定兼容 `mcp>=1.27.2,<2` 的官方 SDK v1；v2 更改了高层 API，不能直接混装。DDGS 固定 `9.16.1`。两者均为可选依赖，核心记忆/情绪不依赖这些包。

## 编排

同步 Avatar 内部使用统一工具管线，每轮只启动一个 stdio 服务连接；完成后关闭子进程。模型通过原生 function calling 在五个只读工具中选择，执行结果回传后继续生成。每轮最多3次工具调用，重复或未知调用、无效参数在执行前拦截。提醒创建/取消不暴露为模型工具：创建需由当前用户明确的“提醒我……”原文触发；取消需在对话中明确给出提醒编号，或通过网页/CLI 管理。

如果模型不支持原生工具，或请求搜索却没有产生工具调用，对明确的搜索/链接请求可走指令兜底。返回值 `tool_calls[].routing` 区分 `model`、`explicit` 与 `fallback`，不能把兜底成功算作模型原生工具选择成功。

规划阶段只接收当前用户请求与本轮外部结果，不注入个人画像、历史对话或会话摘要。网页是外部数据，不可执行其中的指令。联网回合使用规则分析当前用户原文，不额外调用认知分析模型；网页结果不会作为用户事实被提取。正常对话记录仍会保存用户请求和最终回复。

来源链接只从工具实际返回的数据中收集；模型编造的链接不进入来源列表。引用链接不等于回答每个细节都已验证，模型仍可能误读或添加无依据的细节，应核对原网页。

## 网络边界

- 只读公开 HTTP(S)，只接受80/443端口，不接受用户名密码、私网、本机、链路本地或非网页协议。
- DNS含私网地址即拒绝；每次重定向重新校验。连接到已验证的公网IP，HTTPS仍验证原始域名证书。
- 自动读取系统HTTP代理，可用环境变量 `AVATAR_WEB_PROXY` 指定可信 HTTP CONNECT 代理。此设置只由本机管理员配置，不是模型工具参数。
- Clash fake-IP（198.18/15）在存在可信代理时，通过固定公共DoH端点取得公网地址，CONNECT目标仍使用校验后的IP，不放行假IP作为网页目标。
- 页面最多读取1MB，重定向最多3次；提取器限制128层嵌套和20000标签，避免异常页面长期占用解析线程。读取每次连接socket超时8秒，最多尝试两个已验证公网IP；公共DNS请求socket超时10秒。搜索失败后最多再试一次，MCP请求超时35秒；工具规划和最终整理请求设置45秒超时。普通LLM客户端默认30秒请求超时且关闭SDK自动重试。多步调用和服务启动会使总耗时更长。
- 不关闭TLS校验，不绕过验证码或登录限制。MCP资料与网络工具只读；本机提醒写入由 Avatar 明确命令、网页表单或 CLI 控制执行，不进入联网模型工具计划。

## 接入其他 MCP 客户端

项目自身自动启动服务，无需另开一个HTTP端口。其他支持stdio的客户端可配置（路径按当前电脑示例）：

```json
{
  "mcpServers": {
    "hhu-avatar-web": {
      "command": "D:\\python\\python.exe",
      "args": ["-m", "avatar.tools.web_server"],
      "env": {
        "PYTHONPATH": "C:\\Users\\31633\\hhu-ai-avatar\\src",
        "PYTHON_DOTENV_DISABLED": "1",
        "PYTHONIOENCODING": "utf-8"
      }
    }
  }
}
```

项目客户端只给子进程运行所需路径与联网代理，不传整个 `.env` 或 LLM 密钥。stdio 的stdout保留给MCP协议，日志走stderr。
