## 项目概述

带记忆与情感的 AI 虚拟形象底座（河海大学大创），打通「听 → 思 → 演 → 记」全链路。
技术路线：参考 `moeru-ai/airi` 的算法思路，用 Python 重新实现，在中文口型、记忆系统、情绪决策上做出差异化。

## 一、已完成（端到端验证过）

### 1. 记忆模块 `brain/memory.py`
- SQLite 两级记忆：短期会话窗口（deque）+ 长期持久化
- 翻译自 AIRI 的 5 张表：`memory_fragments` / `memory_episodic` / `memory_long_term_goals` / `memory_short_term_ideas` / `memory_tags`
- 用户画像、事件、目标、想法的增删查
- 验证：跨会话画像持久化 `{'名字': '王小明', '偏好': '打篮球'}` ✅

### 2. 情绪模块 `brain/emotion.py`
- PAD 二维情绪（valence / arousal）+ 情绪词典 + 意图分类
- 行为决策树：意图 × 情绪象限 → 语气/温度/语速/音调/口型强度
- 已修复：负面低唤醒词（难过/伤心/疲惫）正确降低 arousal
- 验证：13 个测试全绿；「难过」触发「温柔共情·舒缓」✅

### 3. 口型模块 `face/lipsync.py`
- 自研共振峰元音驱动：LPC + Levinson-Durbin 提取 F1/F2 → 元音 → 张嘴幅度
- 无模型依赖、可解释、可扩展中文口型
- 验证：合成音频输出 98 帧口型参数，静音/有声正确区分 ✅（元音识别准确性待真实语音调优）

### 4. LLM 接入 `brain/llm.py`
- OpenAI 兼容接口，接入本地 Ollama `qwen2.5:7b`
- 验证：真实中文对话 + 记忆召回 + 情感安抚 ✅
- 性能：首次加载 ~130s，之后每轮 0.7s

### 5. 全链路编排 `main.py`
- `Avatar.respond()` 串起 记忆 → 情绪 → 决策 → LLM → 记忆 闭环
- 规则版事实提取（「我叫X」「我喜欢X」写入长期记忆）
- CLI：`python -m avatar.main` 交互式对话

- README、技术选型文档
