# 2.0.0启动与运行配置

当前仍为待门控批准的候选构建。安装正式获批的wheel后，建议在独立虚拟环境运行；本次实际Python为3.10.12，不把其他版本称已测。核心安装含网页资源与第三方声明，可用`hhu-avatar doctor --require-ui`核验。

```bash
# 在已激活且安装hhu-ai-avatar 2.0.0的虚拟环境中
hhu-avatar --version
hhu-avatar doctor --require-ui
OPENBLAS_NUM_THREADS=4 OMP_NUM_THREADS=4 hhu-avatar web --port 8765 --db /absolute/private/avatar.db
```

启动日志给出本机地址和一次性token；保管token，浏览器在本机打开日志中的完整入口。数据库目录需可写，服务保持本机绑定。上述BLAS线程配置是本次短程发布资源门控的明确条件；本机无配置时实际64线程未过32线程上限，不能称任意环境默认线程受限。使用Ctrl+C正常退出；中途崩溃后用同一DB启动，已受理的相同request_id不会自动重执行。

未配置LLM时采用规则降级。真实模型使用`.env`/环境变量的LLM_API_KEY、LLM_BASE_URL、LLM_MODEL，不提交真实密钥。公开部署/真人设备/独立真人质量与多日尚未验收；本次用户授权留待下次，不宣称其通过。可选音频输入需自行安装ASR扩展和本地模型；Edge-TTS需要实际服务可用，doctor不等于真实ASR/TTS验收。

源代码开发启动请使用仓库的`scripts/project-python -m avatar web`，数据位置见[本机布局](../../本机数据布局.md)。发行安装不依赖本服务器的/data固定路径。所有最终校验值及批准状态以总体发布报告为准。
