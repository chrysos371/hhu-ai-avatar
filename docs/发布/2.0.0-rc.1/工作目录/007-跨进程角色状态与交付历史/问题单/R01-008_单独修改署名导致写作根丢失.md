# R01-008 单独修改署名导致写作根丢失

已写请假短信后，单独输入“署名改成【乙】。”，ResponseFrames落到ordinary，后续“再自然一点”不再读取原要求。实际writing-history-validation-v1为49通过1失败，返回signature=None；这是已完成写作来源路径的控制解析缺陷，不是夹具措辞问题。

修复有限裸控制延续：仅在已有writing根时接受完整署名/取消署名/句数/仅正文控制；复用同一署名值语法，全部分句须匹配。引用、问句、第三方描述、附带额外发送均不由此获得写作延续/操作权限。历史根重建复用同一纯解析器；不重放工具或认知。定向与完整/应用门控继续验证，首失败原件保留在006通用runner目录。
