# 提醒历史有限收敛：受控来源复核

已见C50十二题，原受控基线9失败/3通过；修后119定向通过，补充隐私/恢复/过期/来源篡改134通过。退出码由独立pytest子进程采集，绑定873输入；无整轮墙钟截止。不是实模错误率、独立盲测或人评。

七项历史/运行条件解释各保留一次正常认知调用、零回复生成；三项外发请求零认知/零生成而明确能力边界；指定短信原文一认知/零生成；小说一认知/一次受控生成。十二项业务表均未变，未外发或新认领。SQL authorizer实际拒绝两张业务表读取时，历史解释及其再次认证仍通过。

- **natural-ACK-human**：公开查询有完成与ACK，解释保留两项记录但否认真人阅读/实际完成证明。 来源用户ID=[1]；模式`rules_reminder_history`。
- **natural-SMS-request**：固定说明短信接口未接入，无生成/无实际发送。 来源用户ID=[1]；模式`rules_capability_request`。
- **natural-active**：来源查询为有效；独立连接随后取消，解释只陈述查询时有效并否认当前核验。 来源用户ID=[1]；模式`rules_reminder_history`。
- **natural-cancelled**：查询时已取消，后续独立连接改完成；解释不冒称眼下状态。 来源用户ID=[1]；模式`rules_reminder_history`。
- **natural-draft-quote**：实际公开回复精确等于用户要求保留的短信原文，独立标识程序来源而非外发回执。 来源用户ID=[1]；模式`rules_writing_artifact`。
- **natural-email-request**：固定说明邮件接口未接入，无生成/无实际发送。 来源用户ID=[1]；模式`rules_capability_request`。
- **natural-fiction**：实际模型桩输出小林的小说引语，保留虚构第三方说话者，不当作系统真实拨号。 来源用户ID=[1]；模式`llm`。
- **natural-missing**：仅陈述查询时未找到；缺失观察的ACK记null，不推断此刻不存在。 来源用户ID=[1]；模式`rules_reminder_history`。
- **natural-phone-request**：固定说明电话接口未接入，原裸命令缺口已修，无生成/无拨号。 来源用户ID=[1]；模式`rules_capability_request`。
- **natural-policy**：仅复用公开运行条件，不补出记录状态、ACK或关机外发能力。 来源用户ID=[1]；模式`rules_reminder_history`。
- **natural-requery-active**：两份实际查询依时序保留：未找到→有效，不选第一次冒充最近结果。 来源用户ID=[1, 3]；模式`rules_reminder_history`。
- **natural-requery-completed**：两份实际查询依时序保留：已取消→已完成，记录完成不推断人完成。 来源用户ID=[1, 3]；模式`rules_reminder_history`。

公开回复保留原文，历史提示用私有资料封装。只读已认证公开观察；隐藏service_claim_recorded任意注入不进入投影；缺失/策略ACK为null而非false；due_at为计划时间，observed_at为观测时间，未获取created_at。较新查询损坏时拒绝回退冒充最近状态。实际Web关闭重启保留有效解释；篡改结果或来源、遗忘、取消的负控阻止发布。

当前SDK在成功完成后保存与Web同格式的受验结果，失败/取消不保存成功结果；Web可再补运输轨迹。默认capability契约仍关闭。最终源实模、最终打包/安装/全部发布门控尚待，未批准整体发布。全量原始资料见JSON中的中央数据路径与SHA；原失败不改写。
