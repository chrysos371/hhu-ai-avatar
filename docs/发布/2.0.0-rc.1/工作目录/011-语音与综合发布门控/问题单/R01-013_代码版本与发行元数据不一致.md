# R01-013：分发版本身份未充分校验

final-build-v1实际构建退出0、旧有限检查passed=true，代码__version__/前端/构建报告为2.0.0，但项目静态pyproject仍2.0.0rc1，实际wheel METADATA及sdist PKG-INFO均2.0.0rc1。版本更新漏同步静态元数据，原构建器只比前端和运行时代码版本，未比静态声明或实际发行元数据；因此旧通过不能当完整分发通过。

原产物/日志/构建passed字段保留，后验身份门控单独false并阻止发布/安装批准。应同步pyproject，并在输出前校验源码三方版本、构建后校验wheel/sdist元数据和包内版本、独立安装核验importlib.metadata.version与运行时/CLI一致。当前OPEN；完整v15仍运行，不在冻结中改执行输入。native v9尚未冻结或启动GPU，必须绑定修后当前源。
