# R01-015：补充浏览器门控误用历史协议与漏设种子

2026-11-21，源a86fa8bd，15组顺序门控实际10成功/5失败，原始证明及所有数据库、trace保留。

四组误把cycle-23的claim-only历史基线当作当前门槛：三个期望旧页面不自动显示的协议失败，ACK场景本就不在该旧协议登记范围；当前cycle-24 durable recovery四组实际全部成功。不能修改旧协议金标或把原失败改为成功。另privacy只设审计标志，没有设置提醒种子，实际pending为空，隐私屏障尚未在本轮获得验证。

优化目标：当前发布只采用已登记的durable recovery四场景，原claim基线保留供复现；privacy同时显式设置normal_claim种子，绑定最终包UI与当前源码重测；不得跳过隐私或放宽任何断言。新增驱动版本不改旧结果。该项属于发布门控编排问题，不能计作产品隐私已修复；重测仍失败须继续定位。
