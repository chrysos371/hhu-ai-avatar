# 14B 定向小批样例 001

24条训练、12条开发，各6个家族，每家族4/2条。来源为当前AI原创编写与逐项核对，未经人工审核、未经独立质量批准。没有使用旧23条、没有继承其人工偏好审批，没有开始训练或改线上。

| 家族 | 训练任务 | 开发任务 |
| --- | --- | --- |
| 最新用户纠正覆盖旧助手错误 | 数据组件、浇水周期、能力状态、指标含义 | 故障阶段、草稿与实际发送 |
| 角色/发送者切换 | 图书归还、订单询问、排练回复、维修询问 | 作业延期、嘉宾介绍 |
| 未知事实不编造 | 搬家地点、物流时间、小组信息、小说标题 | 故障原因、照片年份 |
| 合法草稿引用 | 便签、JSON、列表、邮件局部修改 | 表头重排、代码嵌套 |
| 情绪与现实边界 | 疲惫、现实朋友、自身经历、排他依赖 | 庆祝、结果保证 |
| 精确交付 | 整除余数、间隔计时、库存、JSON顺序 | 音频裁剪、去重排序 |

全部36条为五消息上下文：system/user/assistant/user/assistant。旧助手回复既有错误也有合法草稿；仅最后回复受监督，历史全部屏蔽损失。不是把诊断原题替换人名后进入训练；故障家族有意重合，开发集仍非独立泛化验收。

`candidates.json` 含每条目标、AI检查理由、内容哈希及审批范围。`build_candidates.py` 只重建候选，不启动训练。加载器采用独立 `experimental-targeted-pilot` 类型；旧部分人工偏好数据仍不能伪装成新类型。导出绑定训练/开发文件、逐条审核记录、筛查实现和当前保护评测哈希。保护集改变后必须重新导出；过长样本导致整批预检/训练拒绝，不能悄悄丢样本。

本轮分别在主项目与整合版导出：

- `data/style-lab/targeted14b-export-20261111-01/`：sft/dev/review/manifest。
- `data/style-lab/targeted14b-preflight-20261111-01/`：14B分词结果及预检。24/12全部通过，训练序列118–157 token，监督目标合计330 token。

这只是很小的上下文纠错/草稿编辑试训材料。静态身份提示并不完整复刻生产后台提示分布；后续必须用整合版完整后台对照评测，不能把开发集损失下降当成线上收益。词面检查通过不等于语义泄漏已获独立批准；同一AI编写和检查仍有偏差。

下一步先做1步显存/保存/独立重载，再根据记录决定是否进行24条单遍6步小训；尚未执行这两阶段。固定14B基座、同后台同提示的无适配器/有适配器对照才能判定训练贡献；4B基线保留，线上另验收。
