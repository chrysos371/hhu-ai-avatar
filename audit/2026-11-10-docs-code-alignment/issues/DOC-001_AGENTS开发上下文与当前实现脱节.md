## 摘要

根目录 `AGENTS.md` 声明为 AI 编码助手改动前必读的项目约定，却仍包含早期实现状态。它把可选语义检索说成“预留”，称仓库“目前仅口型有测试”，并把语音模块放在已完成里程碑中、同时声称全链路已通。这会让后续开发者在错误基线上做方案选择、重复实现已有功能或漏掉集成缺口。

## 证据

- `AGENTS.md` 第 45、56、77–87 行：称 `embed()`/`vector_search()` 是预留、建议实现向量检索；称目前仅 `test_lipsync.py` 有测试。
- `src/avatar/brain/memory.py:666-729`：存在真实 embedder 接入、模型标识/维度校验、SQLite 向量存取、余弦排序及阈值过滤；README/backend 说明可选 Ollama embedding。
- 当前仓库有多个记忆、情绪、Web、工具等测试文件，而不止 `test_lipsync.py`。
- `src/avatar/main.py:68-71` 初始化 ASR 和口型分析器，但全文没有 `transcribe()` 调用；`respond()` 的 TTS 分支仅合成音频并返回 `audio_path`。与 `AGENTS.md` 的“全链路”与 M3/M4 已完成表述不等价。
- `AGENTS.md` 的下一步任务依赖上述旧状态，会把已完成语义检索列成首要待办。

## 影响

该文档会直接影响之后的计划、代码代理判断与测试策略。过时的待办可能造成重复建设；“仅口型有测试”掩盖现有回归覆盖；“语音全链路已完成”可能造成演示能力被高估。
