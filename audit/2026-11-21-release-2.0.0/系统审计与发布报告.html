1. 本版变化与证据范围

标准文本和 Web 入口统一启用来源契约与角色状态：回复关联真实用户行、说话者、修订和隐私代际；画像、数值计算、稿件和提醒快照均带有限来源约束。没有真实发送通道时不把生成文字当成已执行动作。无法核验来源时澄清或拒绝，不冒称已验证。底层 SDK 的显式配置兼容保留。

角色 PAD 可跨独立 OS 进程恢复并按时间衰减；不把旧用户情绪恢复为本轮新观察。Three.js 正式程序形象与 SVG 回退共用实际媒体时钟，覆盖暂停、跳转、倍速、分段、停止、WebGL 上下文丢失恢复和资源释放。发行包包含 UI、许可证和源码来源信息，可脱离仓库安装。

这些变化构成有限工程层面的代际差异。不是训练出了新基础模型，也不据本次开发材料推断通用语义、自然度或真人体验全面提高。

原生 v11 的3处关键错配（代发提议、未答给定主体、稿件新增上课背景）、v13 的3处剩余错配（递交、代答应、复合主体问题）均保留原文和SQL，并触发必要修复。v14为359次调用、候选0/129；v15重新绑定最后的采证源码，未新增盲测题。首轮曾首次运行的6个组合现均已曝光；68题全部是开发复验。

5. 已知限制与下次启动待办

五个共振峰锚区不等于完整中文音素识别，解析结果仍有误判和缺失F2；ü与声调没有被本次实现或校准。公开朗读ASR也不能代替物理麦克风、噪声场景和自由对话人声。旧角色PAD实测从跨OS丢失0改为约0.149732的衰减恢复，证明持久化工程行为，不证明真人感到有情感。

独立真人自然度/任务充分性评审、物理麦克风与音画、真人中文音素/ü/声调校准、多日运行按授权延期。这些未完成目标作为显式发布限制保留，禁止描述成已经通过。参见 用户授权原文、下次启动任务。

模板与有限来源约束可能保留原文而没有显著润色；复杂未支持材料会诚实拒绝。Edge-TTS依赖外部网络可用性。当前时延来自本机受控配置，不能当作外部大模型、目标设备、多人并发或长期性能承诺。
