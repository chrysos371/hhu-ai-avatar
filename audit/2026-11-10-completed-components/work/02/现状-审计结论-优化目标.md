- **优先级：** P1 本机数据写入授权
- **审计来源：** [AUD-002_提醒写工具缺少当前请求授权绑定.md](../../issues/AUD-002_提醒写工具缺少当前请求授权绑定.md)

## 现状

模型写工具执行只检查参数格式，未核对当前用户请求是否授权创建或取消提醒。

## 审计结论

已有审计根据代码路径确认该问题。该项的完整证据、触发条件与影响见审计来源；本文件用于追踪修复，不替代原始审计记录。

## 优化目标

联网模型与通用 MCP server 不提供提醒写工具；提醒写操作仅通过 Avatar 对当前消息的确定性解析、网页表单或 CLI 明确操作执行。

## 验收记录

模型工具和独立 MCP 服务均不暴露提醒写操作；Avatar 只对当前消息中的明确提醒创建或带编号取消命令执行确定性变更。已新增工具注册与主流程回归用例；pytest未运行。
