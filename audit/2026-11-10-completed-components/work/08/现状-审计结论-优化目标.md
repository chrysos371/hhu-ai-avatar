# 08 · 工作台慢请求阻塞

- **优先级：** P2 可用性 / 提醒时效
- **审计来源：** [AUD-008_本机Web单线程请求被同步模型调用占用.md](../../issues/AUD-008_本机Web单线程请求被同步模型调用占用.md)
- **工作状态：** 已完成代码/文档优化；验证状态见验收记录

## 现状

HTTPServer 单线程同步执行模型及工具请求，阻塞提醒轮询与其他管理API。

## 审计结论

已有审计根据代码路径确认该问题。该项的完整证据、触发条件与影响见审计来源；本文件用于追踪修复，不替代原始审计记录。

## 优化目标

限制慢外部请求占用时间，并让非聊天 API 在模型请求等待期间仍可响应；共享角色状态和短期上下文受锁保护。并发回归用例已添加，仍需完整环境运行。

## 验收记录

Web服务改为线程请求，聊天共享状态加锁；LLM默认30秒超时且关闭自动重试。新增并发用例，语法编译通过但未运行 HTTP 并发测试或压力测试。
