# AUD-005 · 全零音频被计算为张嘴状态

- **等级：** P2 · 中
- **类别：** 音频数值边界 / 口型输出
- **状态：** 静态数值路径确认；未运行音频用例
- **置信度：** 高

## 摘要

`LipSyncEngine.analyze()` 给每帧 RMS 加入 `1e-12` 后开方。全零音频的每帧能量因此是 `1e-6`，全局 `peak` 也是 `1e-6`。静音判定使用严格比较 `energy < peak * silence_ratio`，对全零片段不成立；归一化能量接近 1，帧进入 LPC。零输入 LPC 产生非有限系数，后续无元音时分支仍输出约 `0.2` 的张嘴幅度。

## 证据

- `src/avatar/face/lipsync.py:122-125`：RMS 加正数 epsilon、以相对峰值判静音。
- `src/avatar/face/lipsync.py:131-141`：未判静音时对每帧运行 LPC；共振峰/元音不可用时设置 `mouth[i] = 0.2 * energy_norm[i]`。
- `src/avatar/face/lipsync.py:34-60`：全零帧的归一化自相关为零，Levinson-Durbin 的初始预测误差 `e` 为零，`k = -acc / e` 产生 NaN；数值保护没有处理 NaN。
- `tests/test_lipsync.py` 现有用例只检查随机 LPC、元音分类和有声正弦波，没有全零输入或无声 WAV 用例。

## 影响

纯静音 WAV 或被静音化的片段可能输出持续的 `mouth_open≈0.2`、空元音和错误的归一化能量，渲染端会显示角色在静音时轻微张嘴。全静音也可能把非有限 LPC 传播到频谱步骤，增加警告或数值不稳定。

## 建议

1. 先用未加 epsilon 的 RMS 判定静音；仅在归一化时以受控分母防止除零。
2. 若整段最大 RMS 为零或低于绝对底噪阈值，直接返回全部闭嘴、能量为零的帧。
3. 在 `_lpc` 中为零能量/非有限输入提供显式保护，确保输出系数有限。
4. 增加全零、极低幅度噪声、前后静音夹有语音、不同浮点 dtype 的边界用例。

## 验收建议

- 全零输入的所有帧 `mouth_open == 0`、`vowel == ""`、`energy == 0`。
- 静音段稳定闭嘴；有效语音段仍产生有限且范围正确的参数。
- 测试不依赖 NumPy 对 NaN 比较的隐式行为。
